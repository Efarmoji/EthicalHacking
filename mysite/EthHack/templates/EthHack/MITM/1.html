Day 1 : Basement

IP Forwarding

LinuxなどのOSがルーターのように動作して、受け取ったIPパケットを別のネットワークインターフェースに中継する機能

通常のPCは、パケットを「自分あて」でなければ無視します。
でも IP forwarding を有効にすると、「通過点」として振る舞えるようになります。

┌────────┐       ┌──────────────┐        ┌────────┐
│ Victim │ <---> │ Raspberry Pi │ <--->  │ Router │
└────────┘       └──────────────┘        └────────┘
                 （IP forwarding 有効）

Victim → Pi → Router という経路になる

その過程で盗聴、改ざん、ログ保存などMITM攻撃が可能になる

各ツールの役割と特徴

✅ 1. Bettercap（攻撃の実行）

🧠 役割：MITM攻撃の中核（攻撃実行ツール）

ARPスプーフィング、DNSポイズニング、HTTPインジェクションなどを自動で実行できる

Wi-FiのEvilAPやBluetooth、キーストロークスニッフィングなども可能

capletというスクリプト形式で自動化が得意

✅ 2. Wireshark（通信の“目”）

🧠 役割：MITM中のパケットを可視化（GUIパケット解析ツール） ネットワークパケットをリアルタイムで可視化・解析できる

TCP通信、HTTPリクエスト、DNSクエリ、TLSハンドシェイクなどを詳細に確認可能

.pcapファイルのオフライン解析にも対応

🧪 MITM中に使えば：
→ 誰がどこにアクセスしたか、どんなリクエストを送ったかが全部目に見える

✅ 3. tcpdump（通信の“耳”）

🧠 役割：CLIで軽量なパケットキャプチャ（ログ用）

CUIで動く軽量なパケットキャプチャツール

GUIがない環境（Raspberry Piなど）でパケットの記録用に最適

.pcap形式で保存 → Wiresharkで解析もできる

✅ 4. mitmproxy（HTTPS対応の中間者）

🧠 役割：HTTPS通信の中間解析・改ざん

HTTPSにも対応したプロキシ型MITMツール

中継するリクエストをリアルタイムに観察・改ざん可能

Pythonスクリプトで高度な操作ができる（自動でレスポンス書き換えなど）
