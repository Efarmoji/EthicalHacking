PHPGGC

PHPGGC stands for PHP Generic Gadget Chains.
It's a tool used to generate PHP object payloads that exploit PHP object deserialization vulnerabilities.
PHPGGC creates pre-built serialized payloads that, when unserialized by a vulnerable PHP application, can execute arbitrary commands.

It contains gadget chains from real-world PHP libraries (e.g., Monolog, Laravel, Symfony, Guzzle).
A gadget chain is a series of PHP class methods (usually __destruct, __wakeup, __toString) that can be chained to run code during deserialization.

ex : Monolog/RCE1 : Command execution via Monolog logs

PHAR

PHAR stands for PHP Archive.

It's like a .zip or .jar file — a single file that bundles PHP code and metadata, and can be accessed like a virtual filesystem.
