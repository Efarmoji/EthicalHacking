Drupal 7 + uses “Renderable Arrays” CVE-2018-7600

Type : RCE

Because of lack of sanitization in certain AJAX and Form API code paths, RCE can be executed.

Issue of Code

// Before patch, this check was missing in AJAX form handlers:
foreach ($form_state['values'] as $key => $value) {
    if ($key[0] === '#') {
        // keys like '#post_render' were not cleaned out,
        // so they stuck around into rendering.
    }
}

Before patch, this sanitization was missing in several AJAX Form API code paths, enabling attackers to inject #post_render, #markup, etc.

Malicious Render Chain

Drupal uses render arrays of the form:

$render['name'] = [
    '#type' => 'markup',
    '#markup' => $user_input,
    '#post_render' => ['passthru'],
];

#type => 'markup' : It tells Drupal this is raw HTML content.

#markup => $user_input : This is the HTML/text to render — attacker-controlled.

#post_render => ['passthru'] : This is where it gets dangerous. This field says "after rendering #markup, run this function on it".

In short...

This framework contains page render query inside its get request body, so the parameter which page we want to render is controllable.
NOTE : this explanation is simplified. Please think it is not exactly right.

They're processed by Drupal's render and AJAX system. Without the sanitization, malicious input like this

call_user_func_array('passthru', ['user-command']);

in a POST request reaches the Renderer::render() and gets executed.

Key Point

'#post_render' => ['passthru'],
'#markup' => 'id'

The attacker controls which function is called and what gets passed to it, via crafted render array in request parameters.

passthru : is a Drupal function that pass variable to shell command. In this case, we can call this function as stated above.

Flow from POST to Execution

1. POST payload

name[#post_render][]=passthru
name[#markup]=id
name[#type]=markup

2. Render API builds the form without sanitizing # keys.

3. On AJAX render or page render, passthru('id') gets executed.

4. RCE is achieved — all this without authentication or file uploads.
