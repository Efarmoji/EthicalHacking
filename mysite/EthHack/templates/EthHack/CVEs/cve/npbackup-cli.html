npbackup-cli ※Not CVE

This is a common backup tool which does backup/restore/enumarate-snapshot/policy/ploon with a YAML/CONF file.

Actually, it doesn't have vulnerability itself, but with misconfiguration, we can make use of it for privilege escalation.

Jargons and Knowledge

Snapshot : Savinng a file/dir's state at some point. This works as save point.

backup is the deed to take and save it to repositories.

snapshot is a restore point. One backup creates one snapshot.

Vulnerability

This type of backup tool uses YAML/CONF file, and if you have sudo privilege with it, you can backup every directories because literally you are "privileged".

Then, you only have to change the "place" to backup. Create new conf file, and set discretionary location you want to enter.
