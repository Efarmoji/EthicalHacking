Js2Py CVE-2024-28397

- RCE vulnerability : >= version 0.74

- Js2Py CVE-2024-28397: remote code execution risk in js2py up to v0.74; affects apps executing untrusted JS. No upstream patched release noted. Related downstream exploitation seen via pyLoad (CVE-2024-39205).

Jargons and Insights

- Whitelist : Allowed list. In this context, whitelist separetes JS values and others. JS values are wrapped to HJs, and others are PyObjectWrapper.

- obj.own.keys : obj is Python's instances which are immitating JS objects.

The Stem of the Problem

1) Js2Pyjs2py/constructors/jsobject.py

    def getOwnPropertyNames(this, args):
        obj = get_arg(args, 0)
        if not is_object(obj):
            raise MakeError(
                'TypeError',
                'Object.getOwnPropertyDescriptor called on non-object')
        return args.space.ConstructArray(obj.own.keys())

- obj.own.keys returns dict_keys in Python3.

- ConstructArray doesn't do modification in JS array, therefore, the Python objects are revealed in downstream.

2) Js2Py/js2py/base.py

def py_wrap(py):
    if isinstance(py, (FunctionType, BuiltinFunctionType, MethodType,
                       BuiltinMethodType, dict, int, str, bool, float, list,
                       tuple, long, basestring)) or py is None:
        return HJs(py)
    return PyObjectWrapper(py)

- The whitelist doesn't include dict_keys.

- Then, it will be passed to JS as PyObjectWrapper(dict_keys(...)).

- We can back to several classes like .__class__.__base__.__subclasses__(), and we can use subprocess.Popen etc.

2.5) disable_pyimport

- This disables Python to import modules from JS.

- But we can bypass this by making use of revealed wrappers.

3) Js2Py/js2py/evals.py

def eval_js(js):
    e = EvalJs()
    return e.eval(js)

4) Js2Py/js2py/evals.py

    def eval(self, expression, use_compilation_plan=False):
        code = 'PyJsEvalResult = eval(%s)' % json.dumps(expression)
        self.execute(code, use_compilation_plan=use_compilation_plan)
        return self['PyJsEvalResult']

- 3) and 4) are the starting points to the attacking chain.

- These are the entrances to the JS codes evaluation.

Sumarry

①Execute eval_js from web-browser
②eval_js calls getOwnPropertyNames({})
③dict_keys are made into PyObjectWrapper by py_wrap
④Explore the Python attributes from JS
⑤Bypass disable_pyimport and use subprocess.Popen
