IP Routing – The Core Mechanism

Goal : Understanding how IP routing works at Layer 3.

About : routing tables, default gateways, subnetting, and how routers forward packets.

🧠 1. Core Concepts of IP Routing

Concept Explanation
Routing The process of deciding where to send a packet based on its destination IP address
Router A Layer 3 device that reads IP headers and forwards packets accordingly
Routing Table A list of rules that tell a host/router where to send packets
Default Gateway The IP address of the router that a host sends packets to when the destination is outside its own network
Next Hop The next router or device the packet should go to
Subnet A portion of the network; used to decide whether a host is local or remote

🗺️ 2. How Routing Works

📥 Case 1: Same subnet

  • Your IP : 192.168.1.100/24
  • Destination IP : 192.168.1.20

Steps

1. Your OS checks the routing table.

2. It sees the destination is in the same subnet (192.168.1.0/24).

3. Uses ARP to get MAC address of 192.168.1.20.

4. Sends Ethernet frame directly to that MAC.

🌍 Case 2: Different subnet

  • Destination IP : 8.8.8.8(google DNS)

Steps

1. Your OS checks the routing table.

2. Sees it's not in the local subnet.

3. Looks for the default gateway, say 192.168.1.1.

4. Uses ARP to find the MAC of 192.168.1.1.

5. Sends the packet to router, which forwards it toward 8.8.8.8.

🧪 3. Real Routing Table Example (Linux)

$ ip route
default via 192.168.1.1 dev wlan0
192.168.1.0/24 dev wlan0 proto kernel scope link src 192.168.1.100

🔍 What it means:

Entry Meaning
default via 192.168.1.1 Send all unknown destinations to 192.168.1.1 (the router)
192.168.1.0/24 dev wlan0 For local subnet traffic, send directly via wlan0

+jargons

/24

  • It's CIDR notation (Classless Inter-Domain Routing).
  • /24 means the first 24 bits of the IP address are the network part, and the remaining 8 bits are for host addresses.

Example

  • IP: 192.168.1.0/24
  • Binary: 11000000.10101000.00000001.00000000 (32 bits)
  • Network: 192.168.1 (first 24 bits)
  • Usable range: 192.168.1.1 - 192.168.1.254

Proto

  • In Linux's ip route command, proto means the protocol or source of the route.

Example

  • kernel : Automatically added by the OS for interfaces that are up
  • static : Manually added by the user (e.g., ip route add ...)
  • dhcp : Learned from DHCP
  • boot : Learned at boot time
  • ra : Learned via router advertisement (IPv6)

🧩 4. Router Logic (Inside the Router)

Routers perform:

1. Look up destination IP in its routing table.

2. Match the most specific subnet (longest prefix match).

3. Forward to the next hop using its interface.

4. Decrement TTL (Time-To-Live).

5. Recalculate checksum, send packet.

+jargons

Decrement TTL

  • TTL = Time To Live
  • It's a field in the IP packet header that limits how long a packet can live (to prevent infinite loops).
  • Every router that forwards the packet decreases TTL by 1.
  • If TTL hits 0, the router drops the packet and may return an ICMP "Time Exceeded" message.

Checksum

  • The IP header includes a checksum field to verify that it wasn't corrupted in transit.
  • Every time a router modifies the IP header (like TTL), it must recalculate this checksum before forwarding.
  • The checksum is just a math check to make sure bits didn't get flipped.

🔐 5. MITM in Routing Context

Attack How it abuses routing
ARP spoofing Tricks host into using your MAC as gateway
ICMP redirect Tells host: “Use me as the better route”
BGP hijack (advanced) Advertises fake global IP routes (used by nation-states)
Rogue gateway Becomes default gateway on fake AP
DHCP spoofing Injects fake router info during IP assignment

ICMP (Internet Control Message Protocol)

  • A Layer 3 protocol used for network diagnostics and error reporting.
  • It's not used for sending data, but for telling devices something went wrong.

BGP(Border Gateway Protocol)

  • The routing protocol of the Internet (Layer 3).
  • Routers between autonomous systems (ASes) (i.e., ISPs, big networks) use BGP to exchange IP route info.
  • It tells : “If you want to reach 8.8.8.0/24, send traffic to AS15169 (Google) via me.”

DHCP (Dynamic Host Configuration Protocol)

  • A Layer 7 protocol used to automatically assign IP addresses to clients.
  • Instead of manually setting an IP, subnet mask, gateway, DNS, etc., DHCP does it for you.

6. Key Terms

Term Layer Role
IP Layer 3 Addresses packets for delivery across networks
ARP Layer 2 Resolves IP to MAC for same subnet
Default Gateway Layer 3 Router used when no specific route exists
Routing Table Layer 3 OS or router's guide to where packets go
NAT Layer 3 Translates private IPs to public IPs (for internet access)
