Foothold

Also, under the dir /active.htb/Policies/{31B2F340-016D-11D2-945F-00C04FB984F9}/MACHINE/Preferences/Groups, I found xml file.

There is cyphered password and username SVC_TGS.

When the GPP(Group Policy Preference) is created, the xml file storing configuration information is created. During creation of the file, the password is encrypted with AES key for security reason, however, at some point, Microsoft published the AES key and initialization vector.

Though Microsoft patched to not put password into GPP, there is no countermeasure for already created xml file.

Therefore, we can decode it really easyly.

└─$ gpp-decrypt edBSHOwhZLTjt/QS9FeIcJ83mjWA98gw9guKOhJOdcqh+ZGMeXOsQbCpZ3xUjTLfCuNH8pG5aSVYdYw/NglVmQ
