BloodHound Analysis

If we have valid credential, actually we can collect target's AD structure without command shell interaction. Since it's possible unstable, I often use exe or ps1 version. But we have no choice right now.

Then we got zip file for feeding BloodHound.

Info 1. The user judith has WriteOwner right against Management group.

-> We can replace the ownership of this group into ours, and get GenericAll privilege.

Info 2. The Management group has GenericWrite right against management_svc.

If we have the privilege, we can create Shadow Credential against object.

Info 3. The user management_svc has GenericAll right against CA_OPERATOR user.

We can change password for the user.
Also management_svc user has Remote Management right which allows us to use evil-winrm.

Info 4. The username CA_OPERATOR is not default user for Active Directory, but we can assume it's acronym of Certification Authority.

Connecting these information, we can conclude that we can use vulnerable ADCS template if it exits.

First step is making judith member of Management group. First I assign owner right for judith, then get GenericAll right. For that, we can use bloodyAD.

└─$ bloodyAD -d certified.htb --host 10.129.26.250 -u judith.mader -p 'judith09' set owner management judith.mader
[+] Old owner S-1-5-21-729746778-2675978091-3820388244-512 is now replaced by judith.mader on management
└─$ bloodyAD -d certified.htb --host 10.129.26.250 -u judith.mader -p 'judith09' add genericAll management judith.mader
[+] judith.mader has now GenericAll on management

There is ESC9 vulnerablity.

This article disscussing about the condition we need to exploit ESC9.

1. The target doesn't include objectSid checking step.

2. The domain controller has StrongCertificateBindingEnforcement registry set to 0 or 1 (defalut 1), not 2.

3. We have GenericWrite, WriteOwner, or WriteDACL right.

If these conditions are met, we can exploit this vulnerability by changing user's UPN which we have control over into Administrator since the target DC uses UPN not SID.

Exploit
