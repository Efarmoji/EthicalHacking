Foothold

Do you remember that the subdomain we found forbidd direct access? As we can see, the header should enable us to entry the subdomain.

We can add the header manually, but it's more useful to automate editing header. Open burpsuite -> settings -> proxy -> HTTP match and replace rules, and type info like this.

It automatically adds header...

User-Agent: Mozilla/5.0 (X11; Linux x86_64; rv:128.0) Gecko/20100101 Firefox/128.0

It made the subdomain 'dev.siteisup.htb' accessible. And look at the page. We can add the file to the website. File upload vulnerability might be exploitable.

We got source codes of this page with .git directory. For further step, let's observe those codes.

/index.php

    define("DIRECTACCESS", false);

It prevents local file inclusion and blocks us from accessing outside directories like /etc. If there is no page GET parameter is supplied, the page will include checker.php. Let's check the file.

This file checks the file size and file extension. If there is no problem, create directory which is time encoded into md5 under the uploads directory.

In this case, we can make use of vulnerability of the blacklist. To make it safe file upload with black list, we have to block all possible file extensions. If you want to establish secure usage, you need to use whitelist in this case.

Although it blocks several file extension, we can use phar://.

※phar:// is a PHP stream wrapper that lets you access files inside PHAR (PHP Archive) packages like zip/tar. It's often exploited for deserialization or LFI-based RCE attacks.

Now, we know we can use phar://, but we don't know which funcitons/classes are available for establishing reverse shell. So we need to collect extra info. To do that, we can use phpinfo().

└─$ echo "<?php phpinfo(); ?>" > info.php
└─$ zip info.zip info.php
└─$ mv info.zip info.txt

Then, we upload this file and navigate to http://dev.siteisup.htb/uploads/. Make sure you using burpsuite because we need special header to see subdomain pages.

After uploading the file, check the directory because it would be unique name. Next step is, construct the url like this...

http://dev.siteisup.htb/?page=phar://uploads/2623af157bb87c9be73b9a8f397082b6/info.txt/info and visit via burpsuite again.
