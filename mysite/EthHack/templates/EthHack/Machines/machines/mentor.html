Lateral Movement

Because we are in docker, we have to get out of this cage. One of the way we can get out of the container is, to move to other account.

Docker creates a separate subnet (IP range) for each network and assigns container IP addresses from that range. Therefore, we have to enumerate IP address of main target, or other dockers. We can do that with nmap, which we always use.

We can install binary file from here. And serve it with python.

└─$ wget https://github.com/andrew-d/static-binaries/raw/master/binaries/linux/x86_64/nmap
└─$ python3 -m http.server 8000
