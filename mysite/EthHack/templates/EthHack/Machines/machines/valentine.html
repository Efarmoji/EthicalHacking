Foothold

There is a vulnerability which is well-known as Heartbleed.
An attacker sends a tiny payload but claims a big length; the server echoes back that many bytes, copying past the real payload into its own memory (up to ~64 KB). Repeating this leaks sensitive data (cookies, credentials, even private keys). Affects OpenSSL 1.0.1-1.0.1f / 1.0.2-beta, fixed in 1.0.1g or by disabling heartbeats.

This file has root SUID.

Gtfobins says it uses specific socket and if we have permission, we can access there. Therefore, we can get root command line with command hype used before.

hype@Valentine:~$ tmux -S /.devs/dev_sess
