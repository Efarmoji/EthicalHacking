There are several suspiciouis open ports. Searching ipp CUPS 2.2, I found CVE but it's not valid for this version.

Next I searched Zookeeper 3.4.6-1569965 vulnerability, then i found this PoC text file.

Accourding to this poc, there is a web UI page which we can control parameter.

Opening http://$IP:8081, I found UI page. I set revshell command to java.env script following instruction, and got reverse shell.
