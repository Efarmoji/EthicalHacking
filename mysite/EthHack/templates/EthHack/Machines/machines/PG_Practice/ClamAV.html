Searchinng sendmail 8.13.4's vulnerability, i found this vulnerability.

Reading this exploit code, it injects command into recipient parameter.

The first line 'echo ...' opens inetd service under the root bash context and the second line starts inetd service. Therefore, after running this poc file, port 31337 would be accessible wiht root context.
