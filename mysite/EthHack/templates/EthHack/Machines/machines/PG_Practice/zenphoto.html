Though it returned shell once, the shell was not stable. Therefore, I needed to change poc code just a little bit.

The original code of this poc uses below code to generate bash:

        printf("[*] Got root!\n");
        execl("/bin/sh", "/bin/sh", NULL);
}

I replaced the two /bin/sh statement into /bin/bash.

        printf("[*] Got root!\n");
        execl("/bin/bash", "/bin/bash", NULL);
}
