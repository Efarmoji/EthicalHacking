Reading this poc, I found there is admin.php page which we can upload php file by naming it with .phtml extension.

First I jumped the href http://192.168.231.39/admin.php.

I grabbed this webshell, and named it webshell.phtml, and then uploaded it.

We can use webshell by visiting http://192.168.231.39/skins/webshell.phtml.
