Though FTP allows anonymous login, it doesn't return files and other open ports are not vulnerable. Therefore, the main target would be http.

It says it uses Simple PHP Photo Gallery v0.8, and when i searched Simple PHP Photo Gallery v0.8 vulnerability, there is a LFI exploit. However, If I tried several patterns with LFI, I couldn't extract any files.

Therefore, I concluded it's rabbit hole and tried to find another vector.

I found interesting file image.php. I researched the keyword Simple PHP Photo Gallery image.php then found RFI vulnerability here.

Though the version seems to be incompatible, it's worth testing since it's possible that the vulnerability haven't been patched on this version 0.8.

I grabbed this webshell code, and tested RFI. To serve downloaded webshell, I hosted http with python.
