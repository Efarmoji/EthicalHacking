This output reveled a SMB is open.

  • msrpc : Microsoft-RPC (Remote Procedure Call)
  • netbios-ssn : NetBios over TCP/IP : Old protocol for sharing Windows.
  • microsoft-ds : Used for modern SMB (Server Message Block).

Because the set of three are opend, SMB must be enabled.
