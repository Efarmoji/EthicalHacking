We got command line with shaun. However, we can't use it like real command line because this payload uses simple webshell. It's just mimicking CLI, but not actual one. Therefore, we have to create stable reverse shell.

We can do it with nc64.exe. You can use python3 -m http.server for serving nc file, but I reccomend you to use impacket-smbserver for more stable connection.
