Foothold

While I'm trying probable keyword randomly, graphql?query={username} returned interesting hint.

'Cannot query field "username" on type "Query". Did you mean "user"?'

Try it again with this query keyword.

This time, it returned ...

'Field "user" of type "User" must have a selection of subfields. Did you mean "user { ... }"?'

This hint, namely hint2 tells us we can query data with the structure...

graphql?query={user{keyword}}

Inputting standard data key returned hashed password and email address. We can use this on HelpDeskz. Checking with crack station, plain text password 'godhelpmeplz' is revealed.

godhelpmeplz | helpme@helpme.com

Navigating to Submit a Ticket > Next , there is a form where we can upload arbitrary file. Please upload file first. It's ok with txt or png extension.

Searching exploit database revealed there is SQL injection vulnerability, not file uploading. Page here
