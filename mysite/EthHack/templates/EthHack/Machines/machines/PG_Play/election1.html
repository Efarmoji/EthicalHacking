Though there is an admin page, I first take a look at card.php page since we have no credential now.

There is binary string. Because they are not 6 digits per line, I determined this is not base64 encoded, and are raw binary.

I decoded this binary to string using this site. Then, new binary strings are appeared. Decoding it again returned raw ASCII string:

user:1234
pass:Zxc123!@#

We might able to access to admin page with this credential.

This log file includes password assignment for user love. We may get direct access with ssh using this credential.
