FootHold

Fortunately, credential nagiosadmin:admin let me login. Actually, I've got reverse shell on nagios when I've solved another box, so I know which module lead me to reverse shell.

Navigating to Configure -> Core Configure Manager, There is a Commands tab, which I exploit.

Opening the Commands tab, there is Add New button on the top left.

Then, write simple reverse shell command on the Command Line filed, and name it rev_shell(whatever) and press Save button.

Next, after I successfully saved the malisious command, the Apply Configuration column on the right table highlighted in red *. Simply jump to the page and confirm it.

Then, re-navigate Core Configure Manager, press Hosts button, then press localhost again.

You notice that we can select malisious command we generated on Chek_command tab and run it. We can get reverse shell using this.

※Don't forget to open port on your machine using nc.
