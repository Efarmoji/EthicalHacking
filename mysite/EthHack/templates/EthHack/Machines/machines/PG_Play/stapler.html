Since there was no useful information on ftp and port 80 http server, I'll skip these section. But you should never skip enumeration and enumerate them yourself.

After enumerating ftp and port 80, I determined there are no objects I should dig further. Therefore, the next target is port 12380. Since I couldn't login mysql without credential, I decided to gather more information.

This port doesn't hold any additional information. Also, it often has subdirectories, however, if I enumerated with gobuster, there were no pages, even .htpasswd files which always returns 404. Also, when I enumerated directories with gobuster, the http's response was too slow and frustrating.

Since I felt it weird behavior, I launched burpsuite and checked the response.
Then, it responsed with uncommon headers too.

Because it returned Connection: close, I doubt that the protocol may be different, though nmap returned it's http.

Changing the protocol http into https and re-opened the page returned new page. It might hold hidden pages. Let's enumerate.

└─$ feroxbuster -k -u https://$IP -x php > ferox
