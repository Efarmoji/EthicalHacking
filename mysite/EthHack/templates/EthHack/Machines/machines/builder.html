As you can see, this webpage uses jenkins which is open-source automation server. Let's search the version of jenkins because it may have vulnerability.

Luckily, we can find the version on inspect tab. Its version is 2.441.

A little research revealed that Jenkins v2.441 has Arbitrary File Leak Vulnearbility.

CVE-2024-23897s a vulnerability in Jenkins that allows unauthenticated users to read arbitrary files on the server via crafted CLI requests, due to improper handling of command arguments. It affects Jenkins versions before 2.442 and LTS before 2.426.3.

In this case, we can make use of useful file '/proc/self/environ', which is a virtual file in Linux that shows the environment variables of the current process
