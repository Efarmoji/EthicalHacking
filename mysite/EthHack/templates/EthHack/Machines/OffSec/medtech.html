It sounds crazy, but remember. The target is Active Directory, and the applications we need to penetrate are minimal. For instance, SMB and winrm. If the target is WEB server, Postgres, MSSQL, MySQL servers.

Also, if there is no open SMB and WinRM, we can predits the machine uses Linux as OS.
