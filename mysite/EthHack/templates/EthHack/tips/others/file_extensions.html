File Extension List

Extension Explanation
.bat a batch file for Windows, a text file containing a list of commands for the operating system to execute sequentially.
.war A WAR file, which stands for Web Application ARchive, is a standardized file format used in Java-based web development to package and deploy web applications. It is essentially a compressed archive, similar to a ZIP or JAR file, but with a specific structure designed to facilitate the deployment of web applications on a web server or application server (like Apache Tomcat or JBoss).
.jsp A JSP file, or JavaServer Page, is a text document containing static content, typically in formats like HTML or XML, and dynamic content generated by JSP elements. These elements allow for the embedding of Java code snippets and custom tags directly within the page, enabling the creation of dynamic web pages.
.aspx An ASPX file is an ASP.NET Web Forms page processed by the Microsoft .NET runtime (typically on IIS). It mixes static HTML with server-side code (C#, VB.NET) and server controls; at request time the server executes the code and returns rendered HTML. ASPX pages often use ViewState, server controls, and Web.config settings, so misconfiguration (exposed files, insecure deserialization, or improper input handling) can lead to information disclosure or logic vulnerabilities.
.sdf An SDF file usually denotes a SQL Server Compact (SQL CE) database file — a lightweight, file-based database used by embedded or desktop .NET applications. It contains tables, indexes, and data (not executable web pages). If an .sdf is accidentally placed in a web-accessible directory, attackers may download it and extract sensitive data, so it must be protected from public access.
.xlms Windows Excel file. You can unzip it because modern Excel files (like .xlsx and .xlsm) are OOXML packages—basically a bunch of XML and resource files zipped together.
