    History

    When Explanation
    Initial Access What: Gain a first foothold on the target (shell, web‑admin, or service account).
    Lateral Movement What: Move from the initial host to other hosts/services to expand access (new accounts, higher‑value hosts).
    PrivEsc What: Escalate privileges on a host (usually to root) to obtain full control / sensitive data.

    Programming Language Tips

    Technique Name Explanation
    phar:// Used in PHP to exploit file inclusion vulnerabilities; allows triggering deserialization when interacting with crafted PHAR archives.
    python2's input function Unlike Python 3, input() in Python 2 evaluates the input as code, making it highly dangerous if user input is not sanitized.
    @ in 7z and Jenkins CLI The @ symbol allows both tools to read arguments from a file, which can be abused to inject commands or automate interactions.

    Enumeration Tips

    • After Nmap, enumerate directories and subdomains before testing web vulnerabilities.
    • Even if you used Feroxbuster, verify it recursed into deeper directories.

    File Location

    File Name Explanation
    /proc/self/environ Shows environment variables of the current process. Useful for LFI discovery or leaking secrets passed via environment.
    /etc/doas.conf Checks the configuration of doas, a minimal sudo alternative from OpenBSD.
    /etc/apache2/sites-enabled/xx.conf Debian/Ubuntu enabled virtual-host config path. Files (symlinks to sites-available) define domains, DocumentRoot, logs, SSL and proxy settings. Edit as root, run apache2ctl configtest and reload.
    /home/lateral_targ_user/Documents/.backup Sometimes, target user directory has interesting file.

    Web Vulnerabilities

    • Whitelisting is generally safer than blacklisting.
    • If you find a CMS, always check for default credentials.
    • When you find a form, test whether it actually talks to a database.
    • Even if the CMS core has no CVEs, its plugins/themes/dependencies might.

    Git Dumper

    • After dumping a .git directory with git-dumper, run ls -a to reveal hidden files.

    Connection

    • After you get a reverse shell, pivot to SSH using an available id_rsa for stability.

    Requests

    • You can automate header additions in BurpSuite via Settings → Proxy → Match and Replace.

    File Tips

    • File Extensions list is here
    • Determine MIME type: file --mime-type <filename>
    • Show sizes in human-readable form: ls -lh
    • Linux detects types by magic numbers (content). Changing headers can fake types (useful in upload bypass scenarios).
    • List cron jobs: crontab -l

    Privilege Escalation

    Command Explanation
    find / -perm -4000 2>/dev/null Lists all SUID binaries (useful for privilege escalation).
    cat /etc/doas.conf Checks the configuration of doas, a minimal sudo alternative from OpenBSD.
    • Tip: Misconfigured doas rules can be as dangerous as bad sudoers.

    Linux PrivEsc checklist

    No. Check Item Command Explanation
    0 old-netstat netstat -an
    netstat -tulnp
    0 User own executable files find / -type f -executable -user nagios 2>/dev/null | grep -Ev 'proc|cgi' | grep bin
    0 User own file find / -user username 2>/dev/null | grep -Ev proc
    0 History find . -type f | grep -ir "pass" . 2>/dev/null Enumerate histories of all users. You must be on /home dir.
    1 Identity & groups id; whoami; groups See your UID/GID and group memberships (e.g., docker, lxd, adm) that may grant escalation paths.
    2 Sudo rights sudo -l List permitted commands; look for NOPASSWD, wildcards, or env preservation.
    3 SUID binaries find / -perm -4000 -type f 2>/dev/null Run as file owner (often root). Look for known-abusable SUID programs.
    4 Scheduled tasks crontab -l; ls -la /etc/cron*; systemctl list-timers --all Writable scripts or timers run as other users/root.
    5 Writable paths find / -writable -type d 2>/dev/null | grep -vE '^/(proc|sys|dev)' Identify world/group-writable directories for drops/hijacks.
    6 Logs & history history; grep -R "password" ~/.bash_history 2>/dev/null Command history sometimes leaks creds or workflows to hijack.
    17 File capabilities getcap -r / 2>/dev/null Capabilities can grant powerful privileges without SUID.
    7 Temporary dirs ls -ld /tmp /var/tmp Check sticky bit and misuse; race conditions often target temp dirs.
    8 Running processes ps aux --forest Look for root-owned processes you can influence (env, files, sockets).
    9 Mount options findmnt -no TARGET,OPTIONS Identify nosuid/noexec bypass opportunities or constraints.
    10 Exposed .git (raw repo) find / -type d -name ".git" 2>/dev/null Leaked Git repos (esp. under webroots) may expose history/creds. If in a webroot, try raw access (e.g., curl http://site/.git/HEAD).
    11 OS & kernel uname -a; cat /etc/os-release Find kernel and distro version; old kernels/services may have local exploits.
    12 Hostname & users hostname; who; last -n 5 Context and active users; can reveal shared consoles/sessions.
    13 Environment env | sort Search for creds, tokens, unusual PATH, or debug vars.
    14 PATH hijack risk echo $PATH; tr ':' '\n' <<<"$PATH" | xargs -I{} sh -c 'test -w "{}" && echo "{}"' Writable dirs in PATH allow binary/script hijacking in some workflows.
    15 doas (if present) cat /etc/doas.conf 2>/dev/null Misconfigured doas rules can grant root like bad sudoers.
    16 SGID binaries find / -perm -2000 -type f 2>/dev/null Run with group privileges; sometimes abusable for read/write escalation.
    18 Interesting files ls -la /var/backups /opt /srv /var/www 2>/dev/null Backups, scripts, and webroots often contain creds or writable hooks.
    19 Configs & secrets grep -R -iE '(password|passwd|secret|api[_-]?key|token)' /etc /var/www /home 2>/dev/null Search common locations for hardcoded credentials/tokens.
    20 SSH keys ls -la ~/.ssh /home/*/.ssh 2>/dev/null Keys can enable lateral movement or stable access.
    21 Services & units systemctl list-units --type=service --state=running Check for services executing writable scripts or custom ExecStart paths.
    22 Network surface ip a; ip route; ss -tulpn Discover local-only services and listening daemons as root.
    23 NFS (hosted) cat /etc/exports 2>/dev/null no_root_squash can allow root file creation from a client mount.
    24 Containers/VM groups id | grep -E '(docker|lxd)'; docker ps -a 2>/dev/null Membership in docker/lxd can be root-equivalent.
    25 Kernel exploit viability uname -r Note version to research known local kernel priv-esc (compare with distro patches).
    26 Shadow access ls -l /etc/shadow If readable/writable, password hashes can be obtained/altered (rare but critical).
    • Tip: Always verify impact in a controlled or authorized environment.

    Windows PrivEsc checklist

    No. Check Item Command / PowerShell Explanation
    1 Identity & privileges whoami /all Show current user, groups and enabled/disabled privileges (e.g., SeImpersonatePrivilege, SeBackupPrivilege).
    2 Basic system info systeminfo OS version, patch level, hotfixes and installed updates — useful for kernel/local exploit research.
    3 Local users net user / Get-LocalUser List local accounts and identify weak/default accounts or recently added admin users.
    4 Local groups net localgroup / Get-LocalGroup See membership of Administrators, Remote Desktop Users, etc. for lateral escalation routes.
    5 Services (config) sc queryex type= service && sc qc <ServiceName> Identify services with writable ImagePath, unquoted paths, or weak permissions to hijack.
    6 Service permissions accesschk -uwcqv * > services.txt (Sysinternals) Find services where non-admins can start/stop/change binary — often allows privilege escalation.
    7 Scheduled tasks schtasks /query /fo LIST /v / Get-ScheduledTask | Get-ScheduledTaskInfo Look for tasks running as SYSTEM or with writable scripts/paths.
    8 Services & driver file ACLs icacls "C:\Program Files\SomeApp" /recursive Writable directories or files owned by SYSTEM can be replaced to escalate via services/drivers.
    9 Unquoted service paths wmic service get name,pathname | findstr /i " " Unquoted paths with spaces may allow placing an executable earlier in path to run as service user.
    10 Writable folders in service path for /f "tokens=*" %s in ('wmic service get name,pathname ^| findstr /i " " ') do @echo %s Check if non-admin can write to parts of a service binary path — common persistence/escalation vector.
    11 Registry: autoruns & services reg query "HKLM\SYSTEM\CurrentControlSet\Services" /s Inspect service keys, ImagePath and service parameters for misconfigurations or plaintext creds.
    12 Passwords & secrets in files grep -iR "password\|pwd\|secret\|token" C:\inetpub\wwwroot C:\Users 2>NUL Hardcoded creds in config/web.config, scripts, backups, or logs often yield privilege or lateral movement.
    13 Web-app exposures dir /s /b C:\inetpub\wwwroot\.git / try curl http://site/.git/HEAD Exposed repos/configs under webroots can leak creds, connection strings, or source code bugs.
    14 SMB shares & ACLs net share && Get-SmbShare | Format-List Writable or misconfigured shares let attackers drop payloads or replace files that run as SYSTEM.
    15 Scheduled tasks / service binaries owned by others dir /q C:\Windows\Temp & Get-Item -Path "C:\Path\to\exe" | Format-List Owner,Mode Files owned by non-admins in system-run locations may be replaced to escalate.
    16 Credential stores rundll32.exe keymgr.dll,KRShowKeyMgr / Get-Credential Check for stored credentials (Credential Manager, web.config connectionStrings, DPAPI-protected blobs).
    17 DPAPI & recovery powershell -c "Get-ChildItem -Recurse -File -Include *.xml,*.config" Encrypted secrets with DPAPI may be recoverable if DPAPI master key or user profile is accessible.
    18 Token/Impersonation vectors whoami /priv & inspect for SeImpersonatePrivilege If enabled, certain exploits (e.g., Juicy Potato style) may allow NT AUTHORITY\SYSTEM escalation.
    19 Patch & hotfix inventory wmic qfe get HotFixID,InstalledOn Missing MS updates or known-vulnerable components can indicate available local exploits.
    20 Installed software & versions Get-ItemProperty HKLM:\Software\Wow6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* | Select DisplayName,DisplayVersion Identify services/apps with known privilege escalation bugs (e.g., older third-party services).
    21 Event logs wevtutil qe System /c:50 /f:text Errors or repeated failures can expose paths, service names or reveal misconfigurations to abuse.
    22 RDP / WinRM / remote services qwinsta && winrm enumerate winrm/config/listener Misconfigured remote services may allow lateral movement or credential capture (via locked sessions).
    23 DLL & binary hijacking strings <binary.exe> | findstr /i "LoadLibrary" / check writable dirs Writable directories where services load DLLs can be abused by placing malicious DLLs.
    24 ACLs on sensitive files icacls C:\Windows\System32\somefile.exe Weak ACLs on executables, scripts or registry keys may let non-admin modify them to escalate.
    25 Local admin/service accounts reused net user <user> /domain (if domain) / check password last set Passwords reused across services or local accounts can be pivoted into higher privileges.
    26 Containers / virtualization Get-Process -Name "docker","containerd" -ErrorAction SilentlyContinue Membership of container/Hyper-V related groups or presence of containers can lead to escape vectors or host access.
    27 AlwaysInstallElevated (MSI policy) reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer" /v AlwaysInstallElevated Checks the machine-level policy that, if set to 1 (and also set in HKCU), allows MSI packages to install with elevated (SYSTEM) privileges — a highly dangerous misconfiguration exploitable by dropping a crafted .msi.
    28 OS architecture wmic OS get OSArchitecture Returns the OS architecture (e.g., 64-bit or 32-bit). Important to choose correct payloads/binaries and to determine applicable local exploits.
    • Tip: Always validate findings in an authorized lab. Note which checks require extra tooling (Sysinternals, PowerUp, accesschk) and escalate carefully.
