What is javac?

javac is the primary Java compiler included as part of the Java Development Kit (JDK). Its function is to translate Java source code, which is written in human-readable form (typically in .java files), into Java bytecode (stored in .class files). This bytecode is a platform-independent intermediate language that can then be executed by the Java Virtual Machine (JVM) using the java command.

error: release version 7 not supported

You may use v11 for compilation.

JDK installation

sudo apt install -y openjdk-11-jdk

Switch JDK

└─$ sudo update-alternatives --config javac                                                                       

There are 2 choices for the alternative javac (providing /usr/bin/javac).

  Selection    Path                                          Priority   Status
------------------------------------------------------------
* 0            /usr/lib/jvm/java-21-openjdk-amd64/bin/javac   2111      auto mode
  1            /usr/lib/jvm/java-11-openjdk-amd64/bin/javac   1111      manual mode

Press  to keep the current choice[*], or type selection number: 1
