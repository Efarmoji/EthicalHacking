What is xxd?

xxd creates a hex dump of a file (or STDIN) and can do the reverse—convert hex back to binary. It’s perfect for inspecting bytes, carving data, and turning hex-encoded blobs from responses back into real files.

  • File → hex (human or plain stream)
  • Hex → file (reverse with -r)
  • Slice by offset/length; group bytes for readability

Basics

1) File → hex dump (classic view)

kali@kali:~ $ xxd sample.bin | head
00000000: 8950 4e47 0d0a 1a0a 0000 000d 4948 4452  .PNG........IHDR
...

2) File → plain hex stream (no offsets/ascii)

kali@kali:~ $ xxd -p sample.bin | head -2
89504e470d0a1a0a0000000d49484452...

3) Hex → file (reverse)

kali@kali:~ $ xxd -r -p hex.txt > out.bin

4) Carve a slice (offset / length)

kali@kali:~ $ xxd -s 0x200 -l 256 sample.bin   # start at 0x200, show 256 bytes

5) Grouping & width (readability)

kali@kali:~ $ xxd -g 1 -c 16 sample.bin | head   # 1-byte groups, 16 bytes/line
kali@kali:~ $ xxd -g 4 -c 16 sample.bin | head   # 4-byte groups (dword view)

Real-World: Decode hex from HTTP

Example: turn a hex-encoded key into a file

kali@kali:~ $ curl -s https://example.com/key.hex | xxd -r -p > key.pem
kali@kali:~ $ file key.pem
key.pem: PEM RSA private key

Patch Bytes Round-Trip

Edit hex, write back to binary

  • 1) Dump to plain hex: xxd -p in.bin > in.hex
  • 2) Edit in.hex (change bytes)
  • 3) Reverse: xxd -r -p in.hex > out.bin

Compare Files (quick diff)

kali@kali:~ $ diff <(xxd -p file1) <(xxd -p file2)
# or
kali@kali:~ $ cmp -l file1 file2 | head

Quick Reference

FlagMeaningExample
-p Plain hex (no offsets/ASCII) xxd -p file.bin
-r Reverse (hex → binary) xxd -r -p hex.txt > out.bin
-s <off> Seek to offset (dec or 0xhex) xxd -s 0x400 file.bin
-l <n> Limit length (bytes) xxd -s 1024 -l 128 file.bin
-c <n> Bytes per line (width) xxd -c 32 file.bin
-g <n> Group bytes (1/2/4/8) xxd -g 4 file.bin
-u Uppercase hex xxd -u -p file.bin
-b Binary bits view xxd -b file.bin | head
-i C include array xxd -i file.bin > blob.h

Troubleshooting

  • Reverse fails? Ensure input is clean hex (no spaces/headers). Strip whitespace: tr -d '[:space:]' < in.txt | xxd -r -p > out.bin
  • Command not found? xxd ships with Vim: sudo apt install vim-common
  • Wrong slice? Remember offsets are bytes; use -s and -l together.
