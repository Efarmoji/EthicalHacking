chown — Quick Reference

Common Examples

sudo chown www-data /var/www/html/index.php
sudo chown www-data:www-data -R /var/www/html
sudo chown :adm /var/log/custom.log
sudo chown --reference=/etc/hosts ./hosts_copy

Frequently Used Options

Option Meaning Notes
-R Apply changes recursively to a directory and all of its contents. Be careful near symlinks; see traversal options below.
-v Verbose output showing what was changed. Good for dry auditing while running a command.
-c Report only when a change actually occurs. Less noisy than -v.
-f Suppress most error messages (quiet). Use cautiously; you might hide important failures.
-h / --no-dereference Operate on the symlink itself rather than its target. Without this, ownership applies to the link’s target (non-recursive case).

Symlink Traversal (effective with -R)

Option Behavior Recommendation
-H Follow symlinks listed on the command line; do not follow others found during recursion. Use when you explicitly pass a symlink you want followed.
-L Follow all symlinks during recursion. Potentially dangerous; can cross filesystem boundaries unexpectedly.
-P (default) Do not follow symlinks during recursion. Safest default; prevents accidental ownership changes elsewhere.
