SQL useful commands

Code Explanation
user() Returns the MySQL account name and client host currently connected (e.g. 'bob@localhost').
current_user() Shows the account MySQL used to authenticate the session (useful to detect privilege differences vs user()).
database() Returns the name of the currently selected database for the session (or NULL if none).
version() Shows the database server version string (useful for fingerprinting DB type/version).
@@version Server version variable (alternative to version()), often used in injections or fingerprinting.
load_file('/path/to/file') Reads a server-side file (must be readable by DB process and secure_file_priv may restrict it); returns file contents as string or NULL.
information_schema.tables System table listing all tables accessible to the server; query to enumerate databases and tables (e.g. SELECT table_name FROM information_schema.tables WHERE table_schema='db').
information_schema.columns System table listing columns for tables; useful to discover column names and types for a given table.
GROUP_CONCAT(cols) Concatenates multiple row values into a single string — handy to exfiltrate many values in one query (watch max length limits).
CONCAT(a,b,...) Joins values together into one string (useful to build output or combine columns and separators).
UNION SELECT ... Combine results of another SELECT with the original query (commonly used in SQLi to return attacker-controlled columns; column count/types must match).
EXPLAIN SELECT ... Shows the query execution plan — useful for optimization and to understand how the DB will process a query.
LIMIT offset,count Restricts result rows (useful when enumerating large tables or performing incremental extraction).
