What is ltrace?

ltrace (library trace) shows library function calls made by a program at runtime — like malloc(), printf(), system(), or getenv(). Useful for debugging, analyzing binaries, or spotting things like system("tar") or getenv("PATH").

How to use

Command Description
ltrace ./program arg1 arg2 Run a program and print its library calls (e.g. getenv, system) as they occur.
ltrace -p <PID> Attach to a running process by PID and display its library calls.
ltrace -f ./program Follow child processes (trace forks) so library calls from children are also shown.
ltrace -e 'getenv|system' ./program Filter output to show only specific functions (example: getenv and system).
ltrace -s 200 ./program Limit string argument output to 200 characters to avoid very long blobs in the trace.
ltrace -o trace.log ./program Write the ltrace output to a file for later analysis.
ltrace -c ./program Show a summary (counts) of the library calls made by the program.
sudo ltrace ... Run as root (or with appropriate privileges) if tracing processes owned by other users or system services.
