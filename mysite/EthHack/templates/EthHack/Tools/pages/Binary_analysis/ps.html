What is ps?

ps lists running processes and their details (owner, PID, CPU/MEM, state, command). Use it to troubleshoot services, find rogue tasks, and inspect ancestry & environment.

Quick start

The classic: wide, all processes (BSD style)

kali@kali:~ $ ps auxww
  • a = show processes for all users (with a TTY)
  • u = “user” format (adds USER, %CPU, %MEM, etc.)
  • x = include processes without a TTY (daemons)
  • ww = extra-wide (don’t truncate long command lines)

Portable equivalent (SysV style)

kali@kali:~ $ ps -ef                     # like `ps aux` (different columns)
kali@kali:~ $ ps -eo pid,user,pcpu,pmem,stat,etimes,cmd  # custom columns

Process tree (parent/child)

kali@kali:~ $ ps auxfww                  # BSD: f = forest
kali@kali:~ $ ps -ef --forest            # SysV: tree view

Common recipes

Filter & sort

kali@kali:~ $ ps auxww | grep -i nginx | grep -v grep       # quick filter
kali@kali:~ $ pgrep -af nginx                                # better: show PIDs & full cmd
kali@kali:~ $ ps aux --sort=-%cpu | head                     # top CPU
kali@kali:~ $ ps -eo pid,user,pmem,pcpu,comm,args --sort=-pmem | head  # top MEM

Inspect a specific PID

kali@kali:~ $ ps -p 1234 -o pid,ppid,user,stat,stime,etime,cmd  # one process
kali@kali:~ $ ps e -p 1234 -o pid,cmd                           # include environment

Find parent / children

kali@kali:~ $ ps -o pid,ppid,cmd -p 1234          # show parent of PID 1234
kali@kali:~ $ ps --ppid 1234 -o pid,user,cmd      # list children of 1234

Long commands without truncation

kali@kali:~ $ ps auxww                           # BSD: add `ww`
kali@kali:~ $ ps -eo pid,cmd --cols 300          # SysV: widen columns

Useful columns (what they mean)

Column Meaning
USERAccount the process runs as
PID / PPIDProcess ID / Parent process ID
%CPU / %MEMCPU / memory usage (approx.)
VSZ / RSSVirtual size / resident (RAM) in KB
STATState flags (e.g., R running, S sleeping, D uninterruptible, T stopped, Z zombie; + foreground)
START / STIMEStart time/date
ETIME / TIMEElapsed wall time / accumulated CPU time
COMMAND / CMD / ARGSExecutable and arguments (full line with ww)

Flags & formats cheat

Flag What it does Example
a u x All users, user format, include no-TTY ps auxww
-e / -A Every process (SysV) ps -e
-f / --forest / f Full format / tree view ps -ef --forest
-o Choose columns / rename ps -eo pid,user,pcpu,pmem,cmd
--sort=KEY Sort by column (use -KEY desc) ps aux --sort=-%cpu
-p PID / --ppid PID Select by PID / by parent PID ps --ppid 1 -o pid,cmd
e Include environment in output ps e -p 1234 -o pid,cmd
ww Wide/very wide command column ps auxww

Tips

  • BSD vs SysV options: ps aux (BSD) vs ps -ef (SysV). Both are common on Linux; pick one style and learn it well.
  • Long commands: add ww (or increase --cols) to avoid truncation.
  • Environment secrets: ps e may expose env vars; for exact view use tr '\0' '\n' < /proc/<PID>/environ.
  • Find process by port: use ss -tulpn or lsof -i -P -n, then inspect that PID with ps.
  • Kill safely: inspect with ps, then signal with kill <PID> (or kill -TERM / -KILL if needed).
