What is identify?

ImageMagick’s identify prints image metadata (format, size, color depth) and, with -verbose, exposes chunks/profiles where hidden or sensitive data can live (e.g., PNG tEXt/iTXt, “Raw profile type”). Great for quick triage before deeper tools.

Quick checks

kali@kali:~ $ identify sample.png                 # format + geometry summary
kali@kali:~ $ identify -format '%m %wx%h %z-bit\n' sample.png  # custom format
kali@kali:~ $ identify -verbose suspect.png | less -R          # full metadata dump

Hunt for embedded text/hex payloads

kali@kali:~ $ identify -verbose suspect.png | grep -E 'png:(tEXt|iTXt|zTXt)|Raw profile type:' -n
kali@kali:~ $ identify -verbose suspect.png | awk '/Raw profile type:/,/^  signature:/' \
  | grep -E '^[0-9A-Fa-f]+$' | tr -d '\n' | xxd -r -p > extracted.bin

Filter noise to see hex blocks

kali@kali:~ $ identify -verbose suspect.png | grep -vE '^( |Image)'  # keep flush-left lines (e.g., hex)

Useful flags

FlagWhat it doesExample
-verboseFull dump (profiles, chunks, properties)identify -verbose img.png
-formatCustom output (script-friendly)identify -format '%m %w×%h %z-bit\n' img
-quietSuppress warningsidentify -quiet img.png
--versionShow ImageMagick build (features differ by build)identify --version

When to use vs other tools

  • identify: fast structure/metadata/chunks; great first look.
  • exiftool: deeper EXIF/XMP/IPTC on photos (cameras, GPS, dates).
  • strings/xxd: raw carving/inspection once you’ve found suspicious data.
