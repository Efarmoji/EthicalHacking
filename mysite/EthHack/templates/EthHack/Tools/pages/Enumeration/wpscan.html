WPScan

What is WPScan

WPScan is a powerful and widely used WordPress vulnerability scanner designed to help penetration testers and security professionals identify security weaknesses in WordPress websites.

Functionalities

1. WordPress Version Detection

WPScan can detect the version of WordPress running on a website, allowing attackers or security professionals to target known vulnerabilities associated with that version.

2. Plugin & Theme Enumeration

WPScan can enumerate the plugins and themes installed on a WordPress website. This is useful for identifying outdated or vulnerable plugins and themes that may be exploited.

3. Vulnerability Database

WPScan maintains a vulnerability database specifically for WordPress plugins, themes, and core files. It uses this to check if the detected versions of plugins, themes, or the WordPress core have known vulnerabilities.

4. Brute Force Attack

WPScan can perform brute-force attacks on the WordPress login page to guess usernames and passwords. This is useful for identifying weak passwords, but it requires caution as brute-forcing can lock accounts and generate a lot of traffic.

5. User Enumeration

WPScan can enumerate valid usernames for a WordPress site by using techniques such as checking for author-based URLs or leveraging known WordPress API endpoints. This helps in identifying accounts that could be targeted for password attacks.

6. Security Headers Check

It can identify security headers such as X-Content-Type-Options, Content-Security-Policy, and others. These headers are critical in mitigating attacks like XSS and clickjacking.

7. XML-RPC Attack

WPScan can identify if the XML-RPC service is enabled, which has been a target for brute-force attacks. XML-RPC allows remote connections and can be exploited for DDoS attacks, so detecting this can help mitigate risks.

Common WPScan commands

Basic scan

wpscan --url https://example.com

Enumerate Plugins

wpscan --url https://example.com --enumerate p

Enumerate Themes

wpscan --url https://example.com --enumerate t

Check for Vulnerabilities

wpscan --url https://example.com --vulnerabilities

Check for User Enumeration

wpscan --url https://example.com --enumerate u

Brute-Force Login

wpscan --url https://example.com -P /path/to/wordlist -U admin
