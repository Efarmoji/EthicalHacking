What is SQLMap?

SQLMap is an open-source automated SQL injection tool.
It helps you detect and exploit SQL injection vulnerabilities — and extract data, escalate privileges, or even gain shell access.

You can think of it as your SQLi autopilot, which:

  • Identifies injection points (GET/POST/cookie/header/etc.)
  • Figures out the database type and backend
  • Exploits the injection to extract data or run commands

What SQLMap Is NOT

  • It is not a scanner like Nikto or Nmap
  • It doesn't "guess" vulnerable URLs — you provide the target
  • It's not for guessing login credentials via brute force

✅ SQLMap Workflow (Always Follow This)

  • 1. Confirm injection point (-u or --data)
  • 2. Run with --batch --dbs → is it vulnerable?
  • 3. If yes, enumerate: → --tables → --columns → --dump
  • 4. Optionally: → --os-shell or --file-read, etc.

Actual Use Case

sqlmap -u "ws://soc-player.soccer.htb:9091" --data '{"id": "*"}' --dbs --threads 10 --level 5 --risk 3 --batch

  • This command tells SQLMap to test the id parameter in a WebSocket endpoint for SQL injection using aggressive options, then list all database names if successful — all done automatically and quickly.

sqlmap -u "ws://soc-player.soccer.htb:9091" --data '{"id": "*"}' --threads 10 -D soccer_db --dump --batch

  • This command tells SQLMap to attack a WebSocket endpoint, target the id parameter, and dump the full contents of the soccer_db database — using 10 threads for speed, and no interaction required.
