What is searchsploit?

searchsploit is the command-line interface to Exploit-DB on Kali (and other distros). It lets you search local exploit & shellcode references, copy (mirror) PoCs into your workspace, and open them for review— all without a browser.

  • Search by product, version, CVE, or EDB-ID
  • Print local file paths to PoCs; mirror them to the current directory
  • Output in human or JSON for scripting

Quick Start

Find by name/version

kali@kali:~ $ searchsploit openssl 1.0.1
kali@kali:~ $ searchsploit apache 2.2.22
  • Use product + version to triage likely vulnerabilities exposed by banners/Nmap.

Find by CVE or EDB-ID

kali@kali:~ $ searchsploit CVE-2014-0160         # Heartbleed
kali@kali:~ $ searchsploit -p 32745               # show full path for EDB-ID 32745
kali@kali:~ $ searchsploit -m 32745               # mirror 32745.py into CWD
kali@kali:~ $ searchsploit -x 32745               # open/examine PoC
  • -p prints the filesystem path (usually under /usr/share/exploitdb).
  • -m copies the PoC to your current directory (keeps original intact).
  • -x opens the PoC for quick reading (pager).

Tighten or expand matches

kali@kali:~ $ searchsploit "OpenSSH 5.9p1" -t     # search titles only
kali@kali:~ $ searchsploit wordpress plugin:revslider
kali@kali:~ $ searchsploit -c openssh             # case-sensitive
kali@kali:~ $ searchsploit --exclude="dos|poc" openssl  # filter noisy results

Script-friendly output

kali@kali:~ $ searchsploit --json apache 2.2.22 > apache.json
kali@kali:~ $ jq '.RESULTS_EXPLOIT[] | {Title, EDB-ID, Path}' apache.json

Keep the database fresh

kali@kali:~ $ searchsploit -u     # update Exploit-DB local copy
  • Run periodically so new exploits & CVE mappings are available offline.

Useful Flags

Flag What it does Example
-p Print full local file path of a result (often used with EDB-ID) searchsploit -p 32745
-m Mirror (copy) the PoC to current directory searchsploit -m 32745
-x Examine (open) the PoC in a pager searchsploit -x 32745
-w Show Exploit-DB web URL alongside results searchsploit -w CVE-2014-0160
-t Search titles only (fewer, more relevant hits) searchsploit -t "OpenSSH 5.9"
-c Case-sensitive search searchsploit -c OpenSSH
--json JSON output for scripting searchsploit --json apache
--exclude Regex to exclude noisy matches searchsploit --exclude="dos|poc" openssl
-u Update the local database searchsploit -u

Workflow Tips

  • Pipe from recon: take versions from Nmap (-sV) and feed to searchsploit to shortlist PoCs.
  • Prefer targeted checks: a PoC may require specific build/options—always read its notes (-x).
  • Never run unvetted code on production; test responsibly in authorized labs.
