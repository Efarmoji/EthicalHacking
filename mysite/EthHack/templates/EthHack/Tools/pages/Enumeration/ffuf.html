What is ffuf?

ffuf (Fuzz Faster U Fool) is a fast, flexible web fuzzer for discovering hidden files, directories, parameters, and virtual hosts. It performs concurrent requests using wordlists, supports filters (status/size/words/lines), custom headers, recursion, and JSON output — ideal for automated web enumeration and reconnaissance.

Real Case

ffuf -w /usr/share/seclists/Discovery/DNS/bitquark-subdomains-top100000.txt -u http://.../ -H "Host:FUZZ.00.00"

Options You Must Remember

Option Role
-mc Match HTTP status codes — show only responses with the specified codes (comma-separated, e.g. -mc 200,403). Use all to match every code. Defaults include 200,204,301,302,307,401,403.
-s Silent mode — do not print additional information (banner/progress/summary). Useful when piping output or reducing noise.
-fs Filter by response size (bytes) — exclude responses that match the given size(s) or ranges (comma-separated). Handy to remove default/noise page sizes.
-fw Filter by word count — exclude responses that have the specified number of words (or ranges). Useful when content-length varies but word-count is consistent for false-positives.

Useful Options, not indispensable...

Option Role
-t Threads / concurrency. Control parallel requests (e.g. -t 40) to balance speed and server load.
-H Add a custom HTTP header (can be repeated). Useful for auth tokens, host headers, or API keys (e.g. -H "Authorization: Bearer XYZ").
-X Specify HTTP method (GET, POST, PUT, etc.). Use with -d for POST data when fuzzing parameters in request bodies.
-b Send a cookie string with requests (e.g. -b "session=abc123"), useful when fuzzing authenticated areas.
-o Write results to a file (use with -of to set format: json, csv, or html), e.g. -o results.json -of json.
-c Enable colorized output in the terminal for easier reading of results (useful interactively).
