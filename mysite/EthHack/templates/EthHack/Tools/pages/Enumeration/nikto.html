Nikto

Nikto is a powerful open-source web server scanner designed for detecting potential vulnerabilities and misconfigurations in web servers. It is widely used by penetration testers, security researchers, and system administrators to perform comprehensive security assessments on web servers. Nikto performs various tests, including checks for outdated software, known vulnerabilities, and common misconfigurations that could expose the server to attacks.

Functionalities

1. Comprehensive Vulnerability Scanning:

Nikto scans web servers for over 6,700 potentially dangerous files, programs, and configuration issues.

It can detect issues like default configurations, missing security headers, insecure HTTP methods, and outdated versions of software.

2. Support for Multiple Web Servers:

Nikto can scan a variety of web servers, including Apache, Nginx, IIS, Tomcat, and others.

It is capable of identifying the specific web server software and version, which can then be used to check for known vulnerabilities.

3. Detection of Security Issues:

Nikto checks for common vulnerabilities, such as:

  • Server misconfigurations
  • Exposed sensitive files (e.g., robots.txt, .git)
  • Vulnerabilities in outdated software (e.g., vulnerable versions of PHP, Apache, etc.)
  • HTTP security header issues
  • Web application-related flaws (e.g., cross-site scripting, SQL injection points, etc.)

4. Customization and Plugins:

Nikto is highly customizable, allowing you to specify specific URLs or paths to scan, choose particular vulnerability tests, and even use custom scripts.

You can extend Nikto with additional plugins for more specific checks.

5. Fast and Efficient Scanning:

Nikto is designed to quickly perform thorough checks on a target web server. It provides quick feedback on vulnerabilities, making it a useful tool during penetration testing engagements or vulnerability assessments.

6. Full HTTP Request Support:

Nikto supports HTTP(S) and allows scanning over both HTTP and HTTPS protocols, making it versatile for different server configurations.

7. Reporting Capabilities:

Nikto generates detailed reports in various formats, such as HTML, XML, and CSV. These reports can be used for analysis or shared with clients to outline the security issues identified during the scan.

Common Nikto commnad

Basic Scan

  • Perform a basic scan of a target web server:
nikto -h http://example.com

Scan with Specific Options:

  • You can specify additional options, such as scanning over HTTPS or using a proxy:
nikto -h https://example.com -p 443

Scan for Specific Vulnerabilities:

  • Nikto allows you to scan for specific vulnerabilities or tests. For example:
nikto -h http://example.com -Tuning 2
  • The -Tuning option allows you to tune the level of tests, where 2 checks for vulnerabilities that are more critical.

Scan with Authentication:

  • If authentication is required, you can provide credentials with the -auth option:
nikto -h http://example.com -auth username:password

Save Results to a File:

  • You can save the scan results to an HTML or CSV file for reporting
nikto -h http://example.com -o output.html

Scan a Specific Port:

  • Nikto can scan a specific port (default is port 80):
nikto -h http://example.com -p 8080
