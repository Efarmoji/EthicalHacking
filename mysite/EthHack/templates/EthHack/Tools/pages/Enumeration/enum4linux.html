What is enum4linux

enum4linux is a command-line tool (a Perl script) for gathering information from Windows/SMB environments — especially Active Directory domains. It wraps functionality from tools like smbclient and rpcclient to automatically collect user lists, groups, shares, password policy, OS information, and perform RID cycling (to discover local accounts). It's very useful for initial enumeration during penetration testing and vulnerability discovery.

Usage

enum4linux -a $IP
  • -a : stands for “all”. It runs the tool's full suite of enumeration checks against the target (basically a convenience switch that chains together the main individual checks so you don't have to call each flag separately).
