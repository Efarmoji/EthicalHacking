What is nmap?

Nmap (Network Mapper) is a powerful tool for scanning networks to discover hosts, open ports, services, and vulnerabilities. Commonly used in recon and security assessments. It supports scripts (NSE), OS detection, and stealth scanning.

Common Usage

nmap -p- -sCV <TARGET_IP> --min-rate=2000

  • -p-: Scan all 65535 TCP ports.
  • -sC: Run default scripts (equivalent to --script=default).
  • -sV: Detect service versions on open ports.
  • --min-rate=2000: Send at least 2000 packets per second (faster scan).

nmap -sU --top-ports=100 <TARGET_IP>

  • -sU: Scan UDP ports (slower than TCP, often missed).
  • --top-ports=100: Scan only the 100 most common UDP ports.

nmap -Pn --disable-arp-ping <TARGET_IP>

  • -Pn: Skip host discovery (assume host is up).
  • --disable-arp-ping: Disable ARP discovery (used in local networks).
  • Useful when firewall blocks ping/ARP requests.

nmap --script=vuln <TARGET_IP>

  • Runs all NSE scripts in the vuln category to probe for known vulnerabilities on discovered services.
  • Pair with -sV so scripts can use service/version fingerprints for better detection.
  • Results often include CVEs, references, and a brief risk summary. Use only on systems you’re authorized to test.
kali@kali:~ $ nmap -sV --script=vuln <TARGET_IP>
kali@kali:~ $ nmap -sV -p 443 --script=ssl-heartbleed,ssl-ccs-injection <TARGET_IP>  # targeted SSL checks
kali@kali:~ $ nmap -sV --script=vuln --script-timeout=2m --min-rate=1000 <TARGET_IP>
kali@kali:~ $ nmap -sV --script=vuln -oN vuln.txt -oX vuln.xml <TARGET_IP>         # save output

Tips

  • Scope it: add -p (e.g., -p 80,443) to speed up.
  • Troubleshoot: -d (debug) and --script-trace show script I/O when a check fails.
  • Some scripts accept creds/params via --script-args (e.g., user=alice,pass=secret).
