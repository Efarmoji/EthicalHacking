What is cewl?

CeWL (Custom Word List generator) crawls a target website and extracts words to build a targeted wordlist for password attacks and reconnaissance. It can also pull emails and document metadata. Use only against systems you own or are authorized to test.

Quick Start

Basic crawl → wordlist

# crawl depth 2, minimum word length 5, save as words.txt
cewl http://target.example -d 2 -m 5 -w words.txt
  • -d = crawl depth (how many link levels to follow).
  • -m = minimum word length (filters short/low-value tokens).
  • -w = output file for the generated wordlist.

Common Flags & Options

FlagPurposeExample
-d <N> Crawl depth (links to follow) -d 3
-m <LEN> Minimum word length -m 6
-w <FILE> Write wordlist to file -w words.txt
--with-numbers Keep words containing digits (e.g., summer2025) --with-numbers
--email Extract email addresses --email -o emails.txt
--meta Parse metadata from linked docs (PDF/DOCX, etc.) --meta -w meta_words.txt
--ua <STRING> Custom User-Agent header --ua "Mozilla/5.0 (CeWL)"
--auth user:pass HTTP Basic auth for protected areas --auth alice:Secr3t!
-e Follow external links (off-site) -e
-v Verbose output -v

Examples

Targeted list for a login spray

# company site, crawl deeper, include numbers
cewl https://corp.example -d 3 -m 5 --with-numbers -w corp_words.txt

Collect emails for OSINT

cewl https://blog.example --email -o emails.txt

Harvest metadata from documents

cewl https://docs.example --meta -w meta_words.txt

Real Case — GlasgowSmile (lab)

cewl http://192.168.119.79/joomla/administrator/ -d 4 -m 5 -w "$PWD/words.txt"
  • Depth 4 to traverse admin area links thoroughly.
  • Min length 5 to reduce noise while keeping likely tokens (names, brands).
  • Use the output with tools like Hydra, Burp Intruder, John/hashcat rules, or as ffuf wordlists.

Workflow integrations

# ffuf dir discovery with CeWL output
ffuf -w words.txt -u https://target/FUZZ -mc 200,204,301,302

# Hydra login attempt using CeWL list as passwords
hydra -L users.txt -P words.txt http-post-form "/login:username=^USER^&password=^PASS^:F=Invalid"

# John: apply rules to CeWL output to expand variants
john --wordlist=words.txt --rules --stdout | head

Tips & good practice

  • Start with modest depth (-d 2) and increase if needed to avoid excessive requests.
  • Respect robots/ToS and rate-limit in shared labs; consider proxies and identify yourself in UA.
  • Combine --meta + --with-numbers for high-value corporate terms and date patterns.
  • De-duplicate and sort your list before heavy use: 
    sort -u words.txt -o words.txt

Safety & ethics

Only crawl and generate wordlists for environments where you have explicit permission. Limit depth and concurrency to avoid disrupting services. Handle any discovered credentials responsibly.
