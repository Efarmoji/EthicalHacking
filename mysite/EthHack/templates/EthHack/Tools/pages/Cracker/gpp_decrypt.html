What is gpp-decrypt

gpp-decrypt is a small utility/script that decrypts Group Policy Preferences' cpassword values using the publicly known Microsoft AES key, revealing plaintext credentials stored in SYSVOL. It's used by pentesters to audit legacy GPP secrets — use only on authorized systems.

Requisite

  • You need cpasword.
  • This tool can crack only GPP's cpassword in SYSVOL files.

Usage

gpp-decrypt ENCRYPTED_TEXT
