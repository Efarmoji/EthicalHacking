⭐Hashcat

What is hashcat?

Hashcat is a powerful password recovery/cracking tool used to crack hashed passwords using various attack methods. It's popular in cybersecurity, CTFs, and red teaming.

How to use

Example usage

hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt

Options

-a : change attack mode

0 : dictionary attack

-m : Hash type setting

hashcat -h | grep hash_name

And the valid format is...

username:sha256:iterations:base64_salt:base64_hash

Fortunately, there are column "passwd,salt,name".

sqlite3 gitea.db "select passwd,salt,name from user" | while IFS='|' read -r hash salt name; do
  hash_b64=$(echo "$hash" | xxd -r -p | base64)
  salt_b64=$(echo "$salt" | xxd -r -p | base64)
  echo "${name}:sha256:50000:${salt_b64}:${hash_b64}"
done | tee gitea.hashes

1. extract passwd, salt, and name from database

sqlite3 gitea.db "select passwd,salt,name from user"

outputs

e531d3...fb56|8bf3e3...6d34|developer

2. pipe output into a while loop

| while IFS='|' read -r hash salt name; do
  • IFS='|': sets the Input Field Separator to the pipe (|)
  • read -r hash salt name: reads each line and splits it into:
hash the hex-encoded password hash
salt the hex-encoded salt
name the username

3. Turn hash into base64 for hashcat.

  hash_b64=$(echo "$hash" | xxd -r -p | base64)
  salt_b64=$(echo "$salt" | xxd -r -p | base64)
  • echo "$hash": prints the hex string
  • xxd -r -p: converts hex to binary
  • base64: converts binary to base64

NOTE : Hashcat expects the hash and salt in base64, not hex.

4. align those outputs

  echo "${name}:sha256:50000:${salt_b64}:${hash_b64}"
  • Constructs a line for Hashcat mode 10900 (PBKDF2-HMAC-SHA256):

Exmaple output :

⭐Case Codes

Case 1 : when you know a part of the password...

hashcat -m 1400 -a 6 hash wl ?d?d?d?d?d?d?d?d?d -O
Part Meaning
-m 1400 Hash mode 1400 = SHA-256 hashes
-a 6 Attack mode 6 = Wordlist + Mask (Hybrid attack)
File containing the hash(es) to crack File containing the hash(es) to crack
wl Wordlist file (e.g. rockyou.txt, etc.)
?d?d?d?d?d?d?d?d?d Mask = 9 digits, ?d = one digit (0-9)
-O Use optimized kernel (faster, but limits max password length to 31)
