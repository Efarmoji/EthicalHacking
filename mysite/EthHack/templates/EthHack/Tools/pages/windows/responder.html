What is responder?

A tool that listens on the local network and responds to name-resolution and proxy auto-discovery requests (LLMNR / NBT-NS / mDNS / WPAD), collecting client authentication data (e.g., NTLM hashes).

Usage

sudo responder -I tun0 -v
