What is PowerView.ps1?

PowerView is a PowerShell toolkit for Active Directory (AD) enumeration and situational awareness. It helps you map users, computers, groups, ACLs, sessions, trusts, shares, and privilege relationships—so you can plan lateral movement and privilege escalation in Windows domains.

Prepare

/utils/Windows/PowerView.ps1
*Evil-WinRM* PS C:\Users\svc-printer\Documents> Import-Module .\PowerView.ps1

PowerView common commands

Command Explain
Add-ObjectACL Add-DomainObjectAcl (aka Add-ObjectAcl in older PowerView) edits an AD objects DACL to grant chosen rights to a principal. You can add GenericAll, ResetPassword, WriteDacl, or property-specific rights—enabling escalations like password resets, group membership changes, DCSync, or RBCD.
Get-NetDomain Returns basic domain info (name, SID, domain controllers) — equivalent to Get-CurrentDomain.
Get-NetUser <Username> | select memberof Shows the group memberships for the specified user.
Get-NetUser -SPN | select samaccountname,serviceprincipalname Lists accounts with registered SPNs (Kerberoast targets) and their SPN values.
Get-NetGroup <Groupname> | select member Displays members of the named group.
Get-NetComputer | select dnshostname,operatingsystem,operatingsystemversion Enumerates computer objects and shows hostname and OS/version fields.
Find-LocalAdminAccess Scans domain hosts to find machines where the current user is a local administrator.
Get-NetSession -ComputerName <name> -Verbose Lists active SMB/RPC sessions on the target computer (who is connected, from where).
Get-ObjectAcl -Identity <object> Enumerates ACLs/ACEs for the object (shows permissions tied to principals).
Get-ObjectAcl -Identity "Management Department" | ? {$_.ActiveDirectoryRights -eq "GenericAll"} | select SecurityIdentifier, ActiveDirectoryRights Finds objects where "Management Department" has GenericAll rights and lists the SID and rights.
Convert-SidToName <SID> Converts a SID to its human-readable account name.
Find-DomainShare Discovers domain shares and reports accessible/writable shares across hosts.
