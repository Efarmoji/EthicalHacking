What is impacket-changepasswd?

...impacket-changepasswd is a command-line tool from the Impacket suite used to remotely change a user's password in an Active Directory environment.

Use case

1. └─$ impacket-changepasswd retro.vl/banking\$:banking@10.129.234.44 -newpass 'ezpawn!' -protocol rpc-samr

  • Changes the banking$ machine account password in AD to ezpawn! via Impacket's changepasswd using the RPC/SAMR method against 10.129.234.44. It authenticates with current creds (retro.vl/banking$:banking) and, if permitted, sets the new password.

OptionArgument(s)Description

Method of Operations

OptionArgument(s)Description
-protocol, -p {smb-samr,rpc-samr,kpasswd,ldap} Protocol to use for password change/reset
-reset, -admin — Try to reset the password with privileges (may bypass some password policies)
