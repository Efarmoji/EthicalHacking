Commands for Command Prompt

Command How it works
icacls Displays or modifies NTFS permissions on files/folders. Example: icacls C:\test /grant User:F grants full control; /remove removes permissions, /reset restores defaults.
powershell ... -Command "..." Runs the quoted commands non-interactively and then exits the process. Use -NoExit to keep the window open, or append ; Read-Host 'Press Enter' to pause.

Options for Powershell

Options How it works
-NoProfile Starts PowerShell without loading user/system profiles (faster, cleaner, avoids profile side-effects). Good for scripting/reproducibility.
-ExecutionPolicy Bypass Temporarily ignores script-execution policy for this process, allowing scripts to run. Does not permanently change system policy.
