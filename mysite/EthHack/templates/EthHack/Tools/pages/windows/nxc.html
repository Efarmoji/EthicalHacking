What is nxc?

nxc is the CLI command for NetExec—the actively maintained successor to CrackMapExec. It's a red-team/blue-team Swiss-army knife for Windows/Linux networks: enumerate hosts, test credentials, and (with permission) execute commands across protocols like SMB, WinRM, LDAP, MSSQL, SSH, etc.

___________________________________SMB___________________________________

1. └─$ nxc smb retro.vl -u "Guest" -p ""

  • This command attempts to authenticate to retro.vl using the "Guest" user with an empty password over SMB, and enumerates available information if access is granted.

2. └─$ nxc smb retro.vl -u "Guest" -p "" --shares

  • This command attempts to authenticate to retro.vl using the "Guest" user with an empty password over SMB, and specifically enumerates accessible SMB shares if the login is successful.

3. └─$ nxc smb retro.vl -u "Guest" -p "" --rid-brute

  • This tries to authenticate to retro.vl as Guest with an empty password over SMB, then enumerates users by brute-forcing RIDs (up to the default max, e.g., 4000) to list usernames/SIDs even with minimal access.

___________________________________LDAP___________________________________

1. └─$ nxc ldap retro.vl -u "banking$" -p 'ezpawn!' -M adcs

  • This authenticates to retro.vl over LDAP as banking$ with password ezpawn! and runs the adcs module to enumerate Active Directory Certificate Services (e.g., Enrollment Services, CA config, certificate templates, potential ESC misconfigs).

Options for Module

※ maq :
A module that retrieves the value of MachineAccountQuota. This value determines how many computer accounts a domain user is allowed to create.

※get-desc-users :
A module that extracts the description attribute of user accounts. Useful for finding potentially helpful information stored in user descriptions.

※adcs :
A module that gathers information related to Active Directory Certificate Services (AD CS). Useful for enumerating certificate templates, enrollment services, etc.

※subnets :
A module that enumerates subnet information from AD Sites and Services. Helpful for understanding internal network topology.

※bloodhound :
A module for collecting data used by BloodHound. Works with the -c, --collection option to specify what kinds of data to gather (e.g., ACL, Session, Trusts, etc.).
