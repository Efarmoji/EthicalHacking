What is impacket-dpapi?

DPAPI, or Data Protection API, is a Windows component that allows developers to encrypt and decrypt sensitive data by using a key derived from a user's password or the system's domain credentials.

We can decrypt them with impacket-dpapi.

Location for DPAPI Blob

Type I

C:\Users\User\appdata\Roaming\Microsoft\Credentials

Type II

C:\Users\user\AppData\Local\Google\Chrome\User Data\Local State

C:\Users\user\AppData\Local\Google\Chrome\User Data\Default\Login Data

Type III : Wifi Profile

C:\ProgramData\Microsoft\Wlansvc\Profiles\Interfaces\{GUID}\*.xml

Location for Masterkey

C:\Users\User\appdata\Roaming\Microsoft\protect\SID\

Usage

impacket-dpapi masterkey -file 556a2412-1275-4ccf-b721-e6a0b4f90407 -sid S-1-5-21-1487982659-1829050783-2281216199-1107 -password 'ChefSteph2025!'
