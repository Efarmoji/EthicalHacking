What is Procdump.exe?

ProcDump is a process-dump utility from Microsoft/Sysinternals that creates process memory dumps for legitimate purposes like crash analysis and performance investigation. However, attackers can abuse it to dump sensitive process memory (e.g., credentials) and analyze it.

Usage

procdump64.exe -ma PID -accepteula
  • If web browser client is open on the target machine, and if the user may login to some place, you may get credential.
  • Even if the POST request was sent only once, traces of it can remain in memory.
  • Because browsers hold form contents (POST bodies, cookies, auth tokens, JS variables, etc.) in plaintext in memory, dumping the entire process will include whatever plaintext data the browser currently holds.
