What is targetedKerberoast.py?

targetedKerberoast is a Python script that can, like many others (e.g. GetUserSPNs.py), print "kerberoast" hashes for user accounts that have a SPN set.

This tool brings the following additional feature: for each user without SPNs, it tries to set one (abuse of a write permission on the servicePrincipalName attribute), print the "kerberoast" hash, and delete the temporary SPN set for that operation.

This is called targeted Kerberoasting. This tool can be used against all users of a domain, or supplied in a list, or one user supplied in the CLI.

Usage

sudo ntpdate TARGET_IP_OR_DOMAIN
faketime 'OUTPUT_TIME_ABOVE' python3 targetedKerberoast.py --dc-ip IP_ADDRESS -d DOMAIN -u USERNAME -p 'PASSWORD'
