What is impacket-lookupsid?

The impacket-lookupsid (or lookupsid.py) is an enumeration tool within the Impacket library designed to identify existing user and group accounts on a Windows system by brute-forcing Security Identifiers (SIDs).

Usage

impacket-lookupsid 'domain.dmn/guest'@domain.dmn -no-pass
