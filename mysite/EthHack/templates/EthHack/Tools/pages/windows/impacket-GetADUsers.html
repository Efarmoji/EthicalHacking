What is impacket-GetADUsers?

impacket-getadusers is an Impacket script that queries Active Directory via LDAP/LDAP-S to enumerate user accounts and attributes (DN, sAMAccountName, groups, SPNs). Used by pentesters for domain discovery; accepts credentials or Kerberos tickets.

Usage

※You need passowrd.

└─$ impacket-GetADUsers -all active.htb/svc_tgs -dc-ip $IP
