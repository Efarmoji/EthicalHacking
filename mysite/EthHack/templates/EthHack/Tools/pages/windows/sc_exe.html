How to use for PrivEsc

sc.exe config vss binPath="C:\Users\svc-printer\Desktop\shell.exe"
  • sc.exe — Windows Service Controller command-line utility (service management).
  • config — subcommand to change the configuration of an existing service.
  • vss — the target service name (here: Volume Shadow Copy Service) whose config will be modified.
  • binPath="…" — sets the service's image path (ImagePath / BINARY_PATH_NAME) to the given executable and arguments.
  • Effect: updates what executable the service will launch when started; the next service start uses this new image path.
  • Runtime context: the service process runs under the service's configured account (e.g., LocalSystem or a service account) — changing binPath does not change the account.
  • Permissions & detection: modifying a service requires appropriate privileges and is typically auditable (can trigger logs/alerts).
  • Caution: misuse can break the service or create security risks; perform only on authorized systems. 
sc.exe stop vss
sc.exe start vss
