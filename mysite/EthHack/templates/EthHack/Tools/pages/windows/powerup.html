PowerUp.ps1

Post-exploitation PowerShell script that enumerates Windows misconfigurations useful for privilege escalation (unquoted service paths, weak service ACLs, AlwaysInstallElevated, insecure scheduled tasks, stored creds, etc.). Only use on systems you own or are authorized to test.

Quick summary

Runs many checks across services, registry, file ACLs, scheduled tasks, credentials, COM/WMI objects, and common Windows weaknesses — output is human-readable for triage.

Copy-ready examples

Import-Module .\PowerUp.ps1; Invoke-AllChecks | Out-File C:\Users\Public\powerup-checks.txt -Encoding ASCII
Import-Module .\PowerUp.ps1
Get-Command -Module PowerUp
Invoke-ServiceAbuse
Import-Module .\PowerUp.ps1; Invoke-ServiceAbuse; Get-UnquotedServicePaths

Common functions (short)

FunctionPurpose (2 lines)
Invoke-AllChecks Run the whole set of PowerUp checks and print findings (fast overview of host weaknesses).
Invoke-ServiceAbuse Enumerate services for modifiable binaries, weak ACLs, and unquoted paths that enable local escalation.
Get-UnquotedServicePaths List service ImagePath entries missing quotes — check for writable folders in those paths.
Get-AllUserSavedCreds Search credential stores, filesystem and registry for saved credentials that might be reused.

Load vs Run — short

Import-Module .\PowerUp.ps1 — **load** (imports functions into session). Invoke-AllChecks (or any Invoke-*) — **run** (executes checks).

Tips

  • Pipe output to a file for offline review: | Out-File C:\path\file.txt -Encoding ASCII.
  • Importing only loads functions; it does not execute anything.
  • Review the script before running; many forks exist with slightly different checks.
