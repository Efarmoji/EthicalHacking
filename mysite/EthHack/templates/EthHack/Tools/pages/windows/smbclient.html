What is smbclient

...smbclient is a command-line tool to interact with SMB (Server Message Block) shares, like a Linux version of Windows File Explorer for network drives. You can list, upload, download, and delete files on SMB servers.

Real Case

List share

smbclient -L $IP

Access to share

smbclient //Domain_name/Share_name -U 'username%password'

Download whole directory

smb: \> RECURSE ON
smb: \> PROMPT OFF
smb: \> mget *

Write file on the share

smb: \> pu filename write_filename

Write all files in the foloder

smb: \> prompt off
smb: \> mput *

Use case

1. └─$ smbclient //retro.vl/Trainees -U 'Guest'

  • Attempts to connect to the SMB share //retro.vl/Trainees as user Guest.
  • It will prompt for a password (empty if you just press Enter); if access is allowed, you can browse, upload, or download files in that share.

2. └─$ smbclient //retro.vl/Notes -U 'trainee%trainee'

  • Attempts to connect to the SMB share //retro.vl/Notes using the username trainee and password trainee.
  • If the credentials are valid and the share is accessible, you'll get a prompt to interact with the share (e.g., ls, get, put).
