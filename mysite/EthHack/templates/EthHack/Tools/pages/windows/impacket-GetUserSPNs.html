What is Impacket-GetUserSPNs?

Impacket-getuserspns is an Impacket tool that enumerates Active Directory accounts with Service Principal Names (SPNs), requests Kerberos service tickets (TGS) for them, and saves tickets for offline Kerberoasting password cracking. Requires valid credentials or a Kerberos ticket.

※You need password

Usage

impacket-GetUserSPNs active.htb/svc_tgs -dc-ip $IP -request
