Cracking tools

Name Role
john (zip2john) CPU-based password cracker (“John the Ripper”). Supports many formats (Unix shadow, NT/NTLM, ZIP/RAR via zip2john/rar2john, etc.) and attack modes (wordlist + --rules, incremental/bruteforce, masks). Typical flow: extract hashes (unshadow/zip2john) → john --wordlist=rockyou.txt → john --show. Use --format to force the correct hash type. For authorized testing only.
hash_identifier Analyze a password hash string and suggest likely hash algorithms (MD5, bcrypt, NTLM, etc.). Use first to narrow cracking strategy and select proper hashcat mode.
hashcat High-performance password cracker (CPU/GPU). Supports dictionary, mask, rule, and combinator attacks. Use for offline password recovery and testing credential strength once hash type is known.

nxc Use to quickly enumerate, validate credentials, and execute commands across many hosts over SMB/LDAP/WinRM/MSSQL/SSH/RDP. Ideal for credential spraying, share/user/group discovery, and running modules during AD assessments.

impacket-smbserver Spin up a quick SMB share from any folder (SMB2 support, optional creds). Perfect for ad-hoc file transfer, staging tools, and Windows↔Linux drops; use net use to map and copy to pull.
impacket-changepasswd Use to change or reset an AD user/machine account password via SAMR/RPC/LDAP/Kerberos. Helpful when you know valid creds and want to set a known password for persistence or when SMB logon is blocked but RPC works.
Impacket-psexec Runs a remote command/service on a Windows host over SMB by uploading & executing a temporary service binary (uses credentials or NT hashes). Example: impacket-psexec target -u Administrator -p 'Passw0rd'. Use only on systems you own or are authorized to test.

Binary & Runtime Analysis

Name Role
ltrace Trace library calls (e.g. getenv, system, printf) to observe runtime behavior and detect uses of PATH, environment, or dangerous functions.
ps List and inspect processes (ps auxww, trees with --forest, custom columns with -o). Use to find rogue services, check parents/children, view environments (ps e), and sort by CPU/MEM.
identify ImageMagick metadata/chunk inspection. Triage PNG/JPEG for hidden data (tEXt/iTXt, raw profiles), confirm format/bit depth, scriptable with -format.
steghide Steganography tool to hide/extract data inside media (JPEG/BMP/WAV/AU). Embed: steghide embed -cf cover.jpg -ef secret.txt -sf out.jpg; extract: steghide extract -sf out.jpg -xf secret.txt (use -p for passphrase). Useful for CTFs/forensics; note PNG is not supported.

Remote Access

Name Role
SSH Quick link to SSH client/jump host utility for remote Linux host access and tunneling.
snmpwalk Query SNMP agents to enumerate MIB objects (system info, interfaces, routing, installed software). Useful for discovering device details, testing for default/weak community strings, and finding sensitive configuration exposed via SNMP.
snmp_brute
socat Bidirectional data relay between two arbitrary data channels (TCP/UDP/UNIX sockets, files, TTYs, stdio). Useful for port-forwarding, proxying, bridging socket types, debugging services, and temporary tunnels. Powerful and flexible — restrict use to authorized systems and bind to localhost when possible.
chisel Lightweight TCP/UDP tunneller (single static Go binary) that tunnels arbitrary traffic over HTTP(S). Commonly used for reverse tunnels, port-forwarding and pivoting through restrictive networks or proxies. Portable and easy to deploy—monitor for unexpected chisel binaries and outbound tunnels.
openssl Cryptography & TLS toolkit. Generate/manage keys (RSA/ECDSA/Ed25519), create CSRs/self-signed certs, inspect/convert PEM/DER/PFX, and probe TLS endpoints (s_client). Also decrypt/encrypt PEM keys (e.g., openssl rsa -in enc.key -out key.pem) and compute hashes (dgst)—handy for lab certs and key handling.
scp Secure copy over SSH. Download/upload files and directories, use keys/ports/options like -i, -P, -r, -v, and -o (same as ssh). Good for quick transfers; use rsync for resume/large files.

Request Handlers

Name Role
curl Command-line client for sending/receiving HTTP(S) (and other protocols). Ideal for fetching endpoints and testing APIs: set method (-X), send JSON/form data (-d/--data-urlencode, -H 'Content-Type: application/json'), upload files (-F), follow redirects (-L), view headers (-I) and verbose traces (-v). Supports auth (Basic/Bearer), cookies (--cookie/--cookie-jar), proxies (--proxy/--socks5), TLS options (--cacert, --cert, -k), host overrides (--resolve), rate/timing (--limit-rate, -w), and saving responses (-o, -O). Use for debugging and automation; avoid sending secrets to untrusted endpoints.
