Windows : Registory Hive

Hive name Full name Role
HKLM HKEY_LOCAL_MACHINE Whole system : Whole settings for all users.
HKCU HKEY_CURRENT_USER Settings for current user
HKU HKEY_USERS All users settings on the machine. HKCU is a part of HKU
HKCR HKEY_CLASSES_ROOT
HKCC HKEY_CURRENT_CONFIG Hardware infomration currently used. ex) Monitors, Diriver, Device profiles...
