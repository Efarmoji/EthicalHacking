4. Code vulnerabilities

Type Explain
$PATH-HIJACK PATH hijack: placing a malicious binary in a directory that appears earlier in a user’s $PATH so a program invoked by name (not by absolute path) runs the attacker binary. Exploitable when privileged scripts/services run user-supplied programs — can lead to privilege escalation. Detect by listing PATH entries and checking for writable dirs; mitigate by removing writable dirs from privileged users' $PATH, using absolute paths in scripts, and fixing directory permissions.
