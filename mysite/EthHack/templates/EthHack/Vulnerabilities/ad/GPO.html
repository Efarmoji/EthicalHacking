What is Default Domain Policy?

The Default Domain Policy is a Group Policy Object (GPO) in Windows Active Directory that sets domain-wide account policies, such as password requirements and account lockout settings, for all users and computers in the domain

GPO structure

GPC (Group Policy Container)

ex) CN={31B2F340-016D-11D2-945F-00C04FB984F9},CN=Policies,CN=System,DC=contoso,DC=com

What it stores (metadata)

  • GPO GUID (unique identifier)
  • GPO type information (whether it contains User Configuration, Computer Configuration, or both)
  • Version numbers (user version + computer version)
  • GPO links (which Domain or OU the GPO is linked to — stored in the gPLink attribute)
  • WMI filter link (if any)
  • Security filtering (which users/groups can read/apply the GPO)
  • Extensions information (list of Client-side Extension CLSIDs used by the GPO)
  • ACL (who can edit or read the GPO — permissions on the GPC object)

GPT (Group Policy Template)

ex) \\<domain>\SYSVOL\<domain>\Policies\{GUID}

What it stores (actual settings/files)

  • Startup / Shutdown scripts
  • Logon / Logoff scripts
  • Scheduled Task XML files
  • Group Policy Preferences (GPP) XML files
  • Registry.pol (registry-based policy settings)
  • Security settings (.inf files such as GptTmpl.inf)
  • GPO templates and icons (miscellaneous files used by Group Policy)
