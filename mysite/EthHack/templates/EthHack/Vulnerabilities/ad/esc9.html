What is ESC9?

ESC9 is about abusing certificate mapping by combining three conditions:

1. A misconfigured certificate template that doesn't include the objectSid, meaning it skips the security extension that helps tie the certificate to the correct user.

2. The domain controller has StrongCertificateBindingEnforcement registry set to 0 or 1, which allows for weak certificate mapping.

3. Control over a user account, like GenericWrite or WriteOwner, or WriteDacl rights.

When these conditions are met, we can change the user's User Principal Name (UPN) to match the identity we want to impersonate. Then, when we request a certificate for that user, it gets mapped to the impersonated identity during authentication.

Abuse Requirements

1. Enrollment Flag: This attribute controls how certificates are issued by the CA. The flag we want to look for is

msPKI-Enrollment-Flag: CT_FLAG_NO_SECURITY_EXTENSION

- This value tells the CA not to include the objectSid in the certificate, which weakens certificate mapping enforcement.


2. Extended Key Usage (EKU)

- EKUs define what the certificate is allowed to do, like logging into a system or authenticating as a user. For ESC9, we need the EKU to be set to Client Authentication. Flag to look for:

Extended Key Usage (EKU): Client Authentication


3. No Manager Approval Required

- The template should not require any manual approval by a manager or administrator. Flag to check:

Requires Manager Approval = False


4. No Authorization Signatures Required:

- The template should not require additional approval signatures from other users. Flag to check:

Authorized Signatures Required = 0


5. Low-privileged Enrollment Permissions

- The template should allow enrollment by low-privileged users or computers. Flags to look for:

Enrollment Rights: Domain Users, Everyone, Authenticated Users, or Domain Computers


6. Write Permission Over the Targeted User:

We need to have at least WriteOwner, or WriteDACL permissions on the target user we want to impersonate. We can check this using BloodHound.
